# 荒野日记：孤岛 · 社区 Wiki

《荒野日记：孤岛》的**玩家社区资料整理汇编**，以 **Terraria Wiki 风格的树状结构**组织：门户式首页 → 分类枢纽页 → 每个条目独立页面，配多级目录导航与全站检索。

配套一个**纯前端阅读器**（HTML / CSS / JavaScript），零依赖、无后端、可完全离线运行。

> **内容规模**：559 个页面（43 个分类枢纽 + 516 个条目页）、约 47.8 万字、2549 条站内链接（站内链接校验 0 死链）。

---

## 快速开始

### 方式一：一键启动（推荐，Windows）

双击项目根目录的 **`启动Wiki.bat`**，脚本会自动检测 Python、启动本地 HTTP 服务（默认 8000，被占用则自动顺延）并打开浏览器访问 `http://localhost:8000/app/`。

停止服务：关闭那个控制台窗口，或双击 **`停止Wiki.bat`**。

### 方式二：手动起服务（跨平台）

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/app/
```

### 方式三：直接打开（无需 Python）

用 Chrome / Edge 打开 `app/index.html`，点击「选择 wiki 文件夹」导入一次 `wiki/` 目录；内容会缓存到 localStorage，之后可离线直开。

> 只想读内容不想跑程序？直接浏览 [`wiki/`](wiki/) 目录下的 Markdown 文件即可，全部内容都在那里。

## 项目结构

```
.
├── app/                      前端阅读器 + 内容工具链
│   ├── index.html            页面骨架（顶栏 / 侧边目录树 / 正文 / 页内目录）
│   ├── css/style.css         全部样式（浅色 / 深色主题）
│   ├── js/
│   │   ├── markdown.js       轻量 Markdown 渲染器 + 自定义块（hero / cards / infobox）
│   │   ├── data.js           数据层（HTTP 加载 / File System API / 本地缓存）
│   │   ├── search.js         全文检索（分级打分 + 摘要高亮）
│   │   └── app.js            控制器（hash 路由 / 多级目录树 / 面包屑 / 页内目录）

│   │   ├── gw_data.py        数据层：把社区资料解析为结构化数据
│   │   ├── generate_wiki.py  主流程：生成树状页面
│   │   ├── build_manifest.py 生成 wiki/manifest.json 页面清单
│   │   ├── check_links.py    校验 front matter / 死链 / 卡片链接 / 空页
│   │   └── serve.py          本地静态服务（启动 / 停止脚本的调用入口）
│   └── README.md             阅读器的详细使用与维护文档
├── wiki/                     559 个页面的正文（Markdown）+ manifest.json
│   ├── README.md             首页（门户）
│   ├── 01-游戏概览/          角色 / 奇遇 / NPC / 逃离方式
│   ├── 02-核心机制/          生存 / 战斗 / 科技 / 挑战模式 / 建筑 / 钓鱼 / 陷阱……
│   ├── 03-物品/              11 个分类，270+ 物品条目
│   ├── 04-生物/              13 个分类，120+ 生物条目
│   ├── 05-地图/              大地图 / 破风口 / 沉船 / 专属地图 / 特殊地图
│   ├── 06-攻略/              新手指南 / 挑战攻略 / 进阶技巧
│   ├── 07-收集/              成就 / 剧情图鉴 / 账号资源
│   └── 08-附录/              资料来源
├── dataset/                  原始社区资料汇编（内容出处，见下方「资料来源」）
├── .temp_extract/            资料抽取文本、图片笔记、样式指南与早期页面备份
├── 启动Wiki.bat / 停止Wiki.bat

```

**组织原则**：叶子节点（具体物品 / 生物 / 地图 / 天赋 / 奇遇 / NPC）一页一元素，页内含「资料卡 + 获取方式 + 数据 + 用途 + 参见」；分类枢纽页只负责罗列与跳转；面包屑显示完整层级。

## 功能总览

| 功能 | 说明 |
|---|---|
| 门户首页 | 英雄区（标题 / 副标题 / 统计）+ 分类卡片导航 |
| 多级目录树 | 左侧可折叠树，自动只展开当前页面所在路径，当前页高亮并滚入视野 |
| 条目资料卡 | 条目页 infobox：类型 / 数值 / 获取途径一眼可见 |
| 页内目录 | 桌面右侧目录（滚动高亮）；窄屏为标题下置顶折叠目录 |
| 全站检索 | 多关键词、结果分级排序、摘要高亮、键盘操作（`Ctrl+K` / `↑↓` / `Enter` / `Esc`） |
| 深链接 | `#/页面路径@章节锚点` 可收藏分享；站内链接、卡片、面包屑均可跳转 |
| 主题 | 跟随系统 / 浅色 / 深色 三态切换 |
| 离线 | 内容缓存至 localStorage；File System API 目录句柄存于 IndexedDB |

## 内容维护（重新生成）

内容以「生成器 + 手写文章」两种方式维护：

```bash
# 1. 编辑既有 wiki 页面，或资料源（.temp_extract/ 下的抽取文本）
# 2. 重新生成树状内容（会重建 03-物品 / 04-生物 / 05-地图 等分类与条目页）
python app/tools/generate_wiki.py
# 3. 更新页面清单
python app/tools/build_manifest.py
# 4. 校验 front matter / 死链 / 卡片链接 / 空页
node app/tools/check_links.js
```

> **两个必须注意的约定**
>
> 1. `wiki/` 下所有 `.md` 均为 **CRLF** 换行。凡解析这些文件的正则 / 切分都必须写成 `\r?\n`，否则会**静默失效**而不报错。
> 2. `app/tools/` 下的 `.bat` 脚本内容刻意保持**纯 ASCII**（UTF-8 中文的 bat 在 cmd 默认代码页 936 下会被错误解析）；中文提示一律交给 Python 输出。
