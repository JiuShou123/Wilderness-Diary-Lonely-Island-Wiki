本地部署与使用

  1. 方式一：一键启动脚本（推荐）——双击项目根目录下的 启动Wiki.bat， 脚本会自动启动本地服务器并打开本页面；关闭控制台窗口、或双击 停止Wiki.bat 即停止服务。
  2. 方式二：手动启动本地服务器——在项目根目录执行： 
    python -m http.server 8000
    然后浏览器访问 http://localhost:8000/app/，应用会自动读取 wiki/ 目录内容。
  3. 方式三：直接双击打开——用 Chrome / Edge 打开 app/index.html， 点击「选择 wiki 文件夹」导入内容；内容会缓存到浏览器本地存储（localStorage）， 之后即使离线也能直接打开阅读。
  4. 方式四：兼容模式导入——所有现代浏览器可用：点击「选择文件夹（兼容模式）」选择 wiki 文件夹即可，同样支持本地缓存。

内容更新后：若使用本地服务器方式，点击顶部「同步」即可；其他方式请重新导入文件夹，或点击「同步」按提示操作。

功能与快捷键

  • 左侧目录树：按分类浏览全部页面，分组可折叠，且只展开当前页面所在路径（其余自动收起，避免目录过长）；
  • 全局搜索：支持多关键词（空格分隔），标题 / 小节 / 正文分级排序；
  • 右侧「本页目录」：滚动时自动高亮当前章节，点击可平滑跳转；
  • 正文中的站内链接可直接跳转；标题旁的 # 按钮可复制该段落链接；
  • 代码块右上角「复制」按钮可一键复制内容；
  • 快捷键：Ctrl / Cmd + K 聚焦搜索，↑ ↓ 选择结果，Enter 打开，Esc 关闭。

数据与隐私

  • 本应用为纯前端只读工具：不联网、不上传任何数据，所有内容均来自本地文件或本地缓存；
  • 缓存仅保存在当前浏览器（localStorage），可随时使用下方按钮清除；
  • Wiki 内容为玩家资料汇编，非官方资料，数据请以游戏内实际为准。
