# 灌木丛

```wiki-infobox
所属区域 :: 大地图
波数（普通/挑战） :: 7/8
```
| 内容 | 数量 / 掉落 | 方式·耗时 |
|---|---|---|
| 草药丛 | 草药 ×6 | 手 60min |
| 棕榈树 | 阔叶 ×6、木材 ×7 | 手 60min |
| 野薄荷 | 薄荷 ×6-8 | 手 60min |
| 野土豆 | 土豆 ×8 | 手 60min |
| 松树 | 树脂 ×3 | 斧 20min |
| 小野猪 | 小野猪 ×1、健壮的野猪 ×1 | 战斗 |
| 水洼 | 淡水 ×5/6 | 手 60min |
| 蛇 | 毒蛇 ×1（挑战 2） | 战斗 |

- 通关后采集完最后一波淡水，如果刚好遇到夜袭，关游戏重进躲夜袭会错过绿色圆球；该圆球在打完林中暗流时会再获得。
- 挑战模式为新增一波毒蛇。
