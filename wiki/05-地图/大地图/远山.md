# 远山

```wiki-infobox
所属区域 :: 大地图
波数（普通/挑战） :: 9/11
循环资源点 :: 无（远山资源为一次性）。
隐藏关卡 :: 隐秘山洞——猛虎 ×2（各掉落兽皮 1）、虎王 ×1（掉落兽皮 1）、人参 ×1/2（手 60min）。
```
| 内容 | 数量 / 掉落 | 方式·耗时 |
|---|---|---|
| 乱石块 | 石块 ×6-8、石片 ×6-8 | 手 60min |
| 裸露的铁矿 | 铁矿 ×7-9 | 斧 20min |
| 矮树 | 木材 ×4-6 | 斧 20min |
| 狼群 ×2 | 饥饿的狼 ×2、成年狼 ×1 | 战斗 |
| 狼群 ×2 | 饥饿的狼 ×4 | 战斗 |
| 猛虎 | 猛虎 ×2，掉落兽皮 1 | 战斗 |
| 骇人尸骨 | 绳索 ×1 | 手 60min |
| 狐狸 ×2 | 狐狸 ×3（挑战 3、4） | 战斗 |

- 隐藏关卡：隐秘山洞——猛虎 ×2（各掉落兽皮 1）、虎王 ×1（掉落兽皮 1）、人参 ×1/2（手 60min）。
- 远山猛虎大概率掉落兽皮。
- 循环资源点：无（远山资源为一次性）。
- 剧情：打通远山后开启隐藏剧情，点"走进"后点"帮助"，可获得 3 粒女巫的药丸；打通远山选择帮助女巫，回家可触发炼药炉升级（1 升 2）。
