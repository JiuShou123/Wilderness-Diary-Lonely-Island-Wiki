# 林中暗流

```wiki-infobox
所属区域 :: 大地图
波数（普通/挑战） :: 12/14
循环资源点 :: 藤蔓（12 满，得藤条 1）、薄荷（12 满，得薄荷 1）。
隐藏关卡 :: 隐藏密林——野猪群（健壮的野猪 ×3、暴怒的野猪 ×1）×2、野猪王 ×1（掉落兽筋 1、兽血 2-4）。
```

| 内容 | 数量 / 掉落 | 方式·耗时 |
|---|---|---|
| 矮树 ×2 | 木材 ×4 | 斧 20min |
| 野土豆 | 土豆 ×9 | 手 60min |
| 藤蔓 | 藤条 ×7-11 | 手 60min |
| 野猪群 ×2 | 健壮的野猪 ×2、暴怒的野猪 ×1 | 战斗 |
| 野猪群 ×2 | 暴怒的野猪 ×3 | 战斗 |
| 食人鱼群 ×3 | 食人鱼 ×4 | 战斗 |
| 野薄荷 | 薄荷 ×3/4 | 手 60min |
| 真鳄龟 ×2 | 真鳄龟 ×2（挑战 2、4） | 战斗 |

- 隐藏关卡：隐藏密林——野猪群（健壮的野猪 ×3、暴怒的野猪 ×1）×2、野猪王 ×1（掉落兽筋 1、兽血 2-4）。
- 循环资源点：藤蔓（12 满，得藤条 1）、薄荷（12 满，得薄荷 1）。
- 制约关系：藤蔓种群数量越大，薄荷繁衍速度越慢。
- 陷阱：鱼陷阱 → 海参、河豚、红鲑鱼、蝴蝶鱼、鳕鱼。
- 注意：暗流的食人鱼不掉落珍珠，只概率掉落生肉。暴怒的野猪较强，攻略建议用竹枪打食人鱼；打完循环的薄荷建议全部拿走。
