# 竹林

```wiki-infobox
所属区域 :: 大地图
波数（普通/挑战） :: 8/9
循环资源点 :: 健壮的野猪（12 满，得生肉 1）、竹子（24 满，得竹子 1）。
```
| 内容 | 数量 / 掉落 | 方式·耗时 |
|---|---|---|
| 粗壮的竹子 ×2 | 竹子 ×4-6 | 斧 20min |
| 野猪 | 小野猪 ×1、健壮的野猪 ×1 | 战斗 |
| 野猪 ×3 | 健壮的野猪 ×2 | 战斗 |
| 熊 | 灰熊 ×1 | 战斗 |
| 草药丛 | 草药 ×2 | 手 60min |
| 蛇 | 毒蛇 ×1（挑战 2） | 战斗 |

- 循环资源点：健壮的野猪（12 满，得生肉 1）、竹子（24 满，得竹子 1）。
- 制约关系：健壮的野猪种群数量越大，竹子的繁衍速度越慢。
- 该图需要带斧头；打完记得清掉循环的野猪。
