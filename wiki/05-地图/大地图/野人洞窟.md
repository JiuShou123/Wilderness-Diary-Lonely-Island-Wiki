|---|---|---|
| 箱子 | 薄荷 ×4、土豆 ×6 | 斧 20min |
| 藤蔓 ×3 | 藤条 ×14-18 | 手 60min |
| 油脂树 ×2 | 木材 ×10、树脂 ×4 | 斧 20min |
| 箱子 | 淡水 ×4、草药 ×4 | 斧 20min |
| 蜥蜴群 ×2 | 蜥蜴 ×2、火蜥蜴 ×2 | 战斗 |
| 食人族 ×12 | 食人族战士 ×2、食人族队长 ×1 | 战斗 |
| 食人族 ×2 | 食人族战士 ×1、食人族队长 ×1、食人族首领 ×1 | 战斗 |

| 毒蝎 ×3 | 毒蝎 ×6（挑战 2、6、10） | 战斗 |

- 掉落：野人洞窟蜥蜴掉落兽筋 1，食人族掉落毒羽箭 0-4。
- 攻略观点：带炸药的目的就是前两波的火蜥蜴或后面的首领，如果第一波火蜥蜴掉血很多，第二波直接炸即可。
