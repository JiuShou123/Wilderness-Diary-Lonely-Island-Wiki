# 海岸

```wiki-infobox
所属区域 :: 大地图
波数（普通/挑战） :: 3/4
循环资源点 :: 椰子树（16 满），每次砍伐得阔叶 1、木材 1-2、椰子 1-2；海盐（16 满），每次采集得海盐 1。
```
| 内容 | 数量 / 掉落 | 方式·耗时 |
|---|---|---|
| 椰子树 ×3 | 阔叶 ×4、木材 ×2、椰子 ×2 | 斧 20min |
| 蛇 | 毒蛇 ×1（挑战 1） | 战斗 |

- 循环资源点：椰子树（16 满），每次砍伐得阔叶 1、木材 1-2、椰子 1-2；海盐（16 满），每次采集得海盐 1。
- 海盐在触发海盐剧情后，于晴天刷新；从打通溶洞、开启沉船的一刻开始计时，从 8 个开始繁衍。海盐的循环规律与其他资源相同，但只在晴天出现。
