# 仓库

```wiki-infobox
所属区域 :: 破风口
波数（普通/挑战） :: 40/40
```
仓库箱子里的物资有：研究资料 1、木耳 0-2、赤芝 0-2、棕色地衣 0-2、绿色地衣 0-2、黄色地衣 0-2、驯兽鞭 0-1、吹箭 0-2、避毒丸 0-1、暖身丸 0-1、强身丸 0-1、军粮丸 0-1。

| 内容 | 数量 |
|---|---|
| 箱子 ×9 | 斧 20min |
| 变异白鼠 / 变异猎狗 / 变异猪 | 依次循环，数量从 ×3 递增至 ×7，共 27 波 |
| 箱子 | 斧 20min |

- 仓库是混物资船逃离的最后一关，不需要打完；打到一半左右即可凑齐 12 份研究资料（研究员服装在之前关卡打完就直接给）。
- 如果没带清扫者天赋，仓库差不多要打一半才能凑齐 12 份研究资料，运气不好要打一多半。
- 仓库的普通模式和挑战模式是一样的。
- 另有资料称"仓库共 50 波"，与数据库的 40 波不一致，此处以数据库为准，该说法（待考证）。
