# 神秘遗迹

```wiki-infobox
所属区域 :: 特殊地图
```
进入后需在太阳之门与月亮之门中二选一（耗时 15min，此处有进度存档）。

- 月亮之门路线：祭坛 → 开箱子（只能用**手**耗时 60min，不能缩短，得草药 12、羊毛 4）→ 阶梯 → 打遗迹狐猴 2（得珍珠 10）→ 祭坛分流。
  - 跟随流动：采集得人参 4 → 危桥 → 打遗迹狐猴 2（得硫磺 8）→ 长廊 → 镜像长廊 → 打遗迹狐猴 3（得子弹 10）→ 巨大石室 → 打蝙蝠王后（得弹药制造图纸 1）→ 太阳神殿，离开神殿。
  - 找其他路：塌洞 → 未知石室依次选择飞鸟图腾、人像图腾、蛮鱼图腾，各打遗迹石像 1（石像无掉落）→ 神秘石室 → 打开大门直接离开，或四处查看后转动机关；逆时针路线中"月亮大门"第一次推不开，第二次需带匕首推门（会掉外伤），不带匕首则推不开，只能去看太阳壁画后回来推门，或左上角退出；推开后打吸血蝠王（得燧发枪 1）→ 月亮神殿，离开神殿。
- 太阳之门路线：祭坛 → 开箱子（手 60min，得草药 12、羊毛 4）→ 前殿长廊（选"尝试调查"）→ 长廊中段（谨慎通过得珍珠 10，尝试接触得硫磺 8）→ 采集得人参 4 → 风洞 → 后续与月亮之门"跟随流动"路线相同，最终打蝙蝠王后（得弹药制造图纸 1）→ 太阳神殿，离开神殿。
- 注：若在太阳之门不选"尝试接触"，就算是休息整顿也不会掉落危桥，所以想进一次遗迹得 20 珍珠的请走月亮之门。
- 神秘遗迹中的机关/长廊强行通过会掉外伤或精神，务必留意状态。
