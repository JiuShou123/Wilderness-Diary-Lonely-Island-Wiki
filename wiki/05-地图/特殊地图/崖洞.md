# 崖洞

```wiki-infobox
所属区域 :: 特殊地图
```
进入崖洞后依次经历：洞口 → 骇人尸骨（可选"摸索尸体"）→ 阴暗长廊 → 长廊后段 → 打蜘蛛 2（得木材 6）→ 阶梯 → 断崖 → 打蝙蝠 3（得石片 5）→ 采集 60min（得人参 2）→ 陡坡 → 陡坡深处 → 打洞魈 1（得薄荷 3/4）→ 洞魈巢穴 → 壁画，离开崖洞。

- 在骇人尸骨处按"摸索尸体"并耗时 60min 采集，可获得藤条、草药、绷带各 1-3 个。
- 在断崖处选"越过断裂"会掉内伤；若选"找其他路"且继续选择"循风探索"而不是回到断崖，会直接离开崖洞副本。
- 打完洞魈后可以直接左上角离开副本，继续点后面的还要花时间。
- 未选"摸索尸体"等不同分支会影响沿途获得的资源。
