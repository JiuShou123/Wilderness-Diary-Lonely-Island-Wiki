# 健壮的野猪

```wiki-infobox
类别 :: 猪系
生命值（普通） :: 64 / 72
生命值（挑战基础） :: 65
攻击（挑战基础） :: 7
特性 :: 无
出现地点 :: 竹林、林中暗流
```
健壮的野猪 是《荒野日记：孤岛》中的一种生物。

## 属性数据

- **生命值（普通模式）**：64 / 72

**挑战模式基础属性**

| 项目 | 数值 |
|---|---|
| 血量 | 65 |
| 攻击 | 7 |
| 命中 | 100 |
| 闪避 | 2 |
| 移速 | 1 |
| 特性 | 无 |

> 实际数值 = 基础数值 × 天数系数 × 沉船系数 × 难度系数，详见 [挑战模式](../../02-核心机制/挑战模式.md)。

**随生存天数成长**

| 天数区间 | 攻击/血量 |
|---|---|
| 1–20 日 | 攻7 66 |
| 21–40 日 | 攻7 -74 |
| 41–60 日 | 攻8 -75 |
| 61–70 日 | 攻8 72-80 |
| 71–100 日 | 攻9 81-82 |
| 101–200 日 | 攻9 84 |
| 201 日以上 | 攻9 90-98 |
