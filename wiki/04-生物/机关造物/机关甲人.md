# 机关甲人

```wiki-infobox
类别 :: 机关造物
生命值（挑战基础） :: 80
攻击（挑战基础） :: 20
特性 :: 防御：5
出现地点 :: 沉船一侧（诡船／桅船）各房间
```

机关甲人 是《荒野日记：孤岛》中的一种生物。

## 战斗提示

- 机关甲人为挑战模式／沉船一侧的敌人。基础属性：机关甲人防 5、机关甲兵防 5（血量 230）、机关猛兽防 3 且闪避 30。
- 机关甲人掉落为木材 1，另概率掉落石块、藤条、石片、铁矿各 0–1。
- 另注：**机关甲人（伙伴系统）** 与战斗中的机关甲人系不同名，伙伴机关甲人相关内容见 [NPC系统](../../01-游戏概览/NPC/NPC一览.md)（同名提示）。
