# 毒蛇

```wiki-infobox
类别 :: 其他生物
登场 :: 挑战模式专属
生命值（挑战基础） :: 130
攻击（挑战基础） :: 16
特性 :: 无
```
毒蛇 是《荒野日记：孤岛》中的一种生物，仅在挑战模式登场。

## 属性数据


**挑战模式基础属性**

| 项目 | 数值 |
|---|---|
| 血量 | 130 |
| 攻击 | 16 |
| 命中 | 95 |
| 闪避 | 5 |
| 移速 | 2 |
| 特性 | 无 |

> 实际数值 = 基础数值 × 天数系数 × 沉船系数 × 难度系数，详见 [挑战模式](../../02-核心机制/挑战模式.md)。

**随生存天数成长**

| 天数区间 | 攻击/血量 |
|---|---|
| 1–20 日 | 攻16 126-130 |
| 21–40 日 | 攻17 134-143 |
| 41–60 日 | 攻18 145-150 |
| 61–70 日 | 攻19 145-162 |
| 71–100 日 | 攻20 161-162 |
| 101–200 日 | 攻20 165-170 |
| 201 日以上 | 攻22 180-192 |
