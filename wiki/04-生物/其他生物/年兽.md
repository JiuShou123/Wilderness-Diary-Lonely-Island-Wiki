# 年兽

```wiki-infobox
类别 :: 其他生物
登场 :: 挑战模式专属
生命值（挑战基础） :: 100
攻击（挑战基础） :: 15
特性 :: 无
```
年兽 是《荒野日记：孤岛》中的一种生物，仅在挑战模式登场。

## 属性数据


**挑战模式基础属性**

| 项目 | 数值 |
|---|---|
| 血量 | 100 |
| 攻击 | 15 |
| 命中 | 100 |
| 闪避 | 10 |
| 移速 | 1 |
| 特性 | 无 |

> 实际数值 = 基础数值 × 天数系数 × 沉船系数 × 难度系数，详见 [挑战模式](../../02-核心机制/挑战模式.md)。
