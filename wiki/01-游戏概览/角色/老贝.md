# 老贝

| 项目 | 内容 |
|---|---|
| 定位 | 探险家 / 前军官 |
| 官方简介 | 前英国陆军军官，长期的军旅生活使其有着强壮的体格和灵敏的身手。平时不爱说话，做事一板一眼。但是很爱喝酒。 |
| 原皮特性 | 迷路概率降低 |
| 专属建筑 | **高索台**（可大大缩短营地到各资源点之间来回的时间） |
| 专属逃离 | 热气球逃离（专属地图：海盗营地） |
| 通关解锁 | 配方：**老贝的草裙**（解锁后所有角色均可制作） |
| 可制作专属物品 | 老贝的研磨器（将石块打磨成石片，需先获得配方） |
| 奇遇 | 不屈军魂、狂化战士、赏金猎人 |
