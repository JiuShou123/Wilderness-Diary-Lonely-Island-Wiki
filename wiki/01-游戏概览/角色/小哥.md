# 小哥

| 项目 | 内容 |
|---|---|
| 定位 | 野食家 / 美食视频博主 |
| 官方简介 | 微博美食视频博主，一本正经做美食节目，不被时间和社会束缚，随心所欲地填饱肚子。有着「食在野，醉在食」的能力。 |
| 原皮特性 | 可在非营地的地方制作食物（野食）；食用食物或药品后 1 小时内基础攻击力 +7，并恢复失眠值 |
| 专属建筑 | 无 |
| 专属逃离 | 穿越逃离（专属地图：古代遗迹） |
| 通关解锁 | **小哥的手电**（所有角色开局携带，相当于更轻便持久且轻量的火把） |
| 可制作专属物品 | 小哥肉酱（需先获得配方） |
| 奇遇 | 元日食神、圣诞小哥、绝味小哥 |

补充说明：

1. 小哥的野外制作需要随身携带木材与生肉/土豆，且不享受科技加成。
2. 食用食物或药品后 1 小时内「基础攻击力 +7」对近战、远程、投掷均有效；吃膏药、绷带等药品同样触发；同时附带约 12% 的近武/远武命中率加成（详见[战斗系统](../../02-核心机制/战斗系统.md)与[资料来源](../../08-附录/资料来源.md)）。
