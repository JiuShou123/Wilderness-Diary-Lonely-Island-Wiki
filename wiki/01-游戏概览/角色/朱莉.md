# 朱莉

| 项目 | 内容 |
|---|---|
| 定位 | 工艺师 / 贵族 |
| 官方简介 | 坎贝尔家族的小女儿，哥哥在三年前失踪，与叔叔竞争后继承伯爵爵位。对冶金有着天分，擅长游泳和滑雪，喜爱收集袖珍手枪，还会中国刺绣。 |
| 原皮特性 | 制造出耐久工具的概率更高 |
| 专属建筑 | **冶金炉**（可制作武士刀、重连弩、精致炸药、弹药、伪袖珍手枪等强力武器） |
| 专属逃离 | 制作铁船逃离（专属地图：海盗营地） |
| 通关解锁 | 配方：**朱莉的长弓**（解锁后所有角色均可制作） |
| 可制作专属物品 | 铁锭（开启专属逃离剧情后可炼制）；弹药（需先在神秘遗迹击败蝙蝠王后获得「弹药制造图纸」）；伪袖珍手枪（需先获得配方） |
| 奇遇 | 双旦女爵、幽灵公主、塔罗女巫、冰雪公主 |

补充说明：

1. 朱莉的「制造耐久工具概率更高」指制造时有概率产出更耐久的同名装备，而非其制造的所有装备都更耐用。
2. 铁锭为朱莉专属逃离材料，只能用于专属逃离（用铁矿在冶金炉烧制）。
