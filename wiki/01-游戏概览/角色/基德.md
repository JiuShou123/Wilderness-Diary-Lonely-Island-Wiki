# 基德

| 项目 | 内容 |
|---|---|
| 定位 | 船长 / 海盗与赌徒 |
| 官方简介 | 大名鼎鼎的基德船长，身为海盗的同时也是一名赌徒。认为自己是航海家，偶尔在海上和别人做做生意。精通社会交际。 |
| 原皮特性 | 战斗中有概率怒吼（恐吓）使怪物直接失去战斗力；可通过燃烧纸牌窥探命运（获得增益） |
| 专属建筑 | **赌桌**（烧牌获得 buff；打通竹林后触发剧情获得纸牌后可制作） |
| 专属逃离 | 建造高塔，获得军舰搭救（专属地图：至高之地） |
| 通关解锁 | **基德的罗盘**（所有角色开局携带，可显示当前地图循环资源点的资源是否已满） |
| 可制作专属物品 | 纸牌（需先获得配方） |
| 奇遇 | 夺宝怪盗、异变死神、新月狼人、彩蛋兔爷 |

补充说明：

1. 基德的怒吼（恐吓）直接使怪物丧失战斗力。被恐吓的怪物计入每日挑战的「击败」进度，但不计入成就中「杀死多少只某类怪物」的统计。
2. 基德烧牌（赌桌）的具体牌面效果见[物品图鉴](../../03-物品/物品总览.md)与[战斗系统](../../02-核心机制/战斗系统.md)。
