# 罗兰

| 项目 | 内容 |
|---|---|
| 定位 | 美食家 / 厨师 |
| 官方简介 | 在厨房摸爬滚打了十二年，有着出色的料理技巧，尤其爱尝试开发新的菜品。但是眼界有限，遂申请成为随船厨师出海。性格豪迈直爽，积极乐观。 |
| 原皮特性 | 烹饪出美味食物的概率更高；可以烹饪**秘制炖肉** |
| 专属建筑 | **酿酒台**（可制作土豆酒） |
| 专属逃离 | 抢夺海盗船逃离（专属地图：圣果树） |
| 通关解锁 | 配方：**荒野烤肉**（解锁后所有角色均可制作） |
| 可制作专属物品 | 秘制炖肉；奇特香料（需先获得配方） |
| 奇遇 | 战地厨师、御蜂厨医、新春厨神、春语妙厨 |

补充说明：

1. 罗兰烹饪出美味食物的概率更高——在制作逃离材料（如肉汤）时出现「美味」品质属于额外结果，不影响正常产出。
2. 罗兰可制作的「奇特香料」不能直接使用，只能用于与野蛮人交易（需先获得配方）。
3. 使用罗兰通关后解锁的「荒野烤肉」配方为账号级解锁，所有角色均可在营火制作。
