# 夺宝怪盗

```wiki-infobox
归属角色 :: 基德
类型 :: 奇遇
```
- **归属角色**：基德
- **简介**：偶然的机会让基德在燃烧纸牌时发现了新的命运指向。燃烧纸牌时可能发现藏宝地点，在藏宝点可以发现大量物资。

| 技能 | 满级效果 |
|---|---|
| 预知 | 提前预知 20 个无宝藏板块 |
| 玄学 | 进一步提高发现宝藏概率 |
| 灵长 | 对灵长目动物伤害提高 50% |
| 灵巧 | 战斗中闪避概率提高 14.5% |

> **提示**：宝藏共 6×9=54 个格子；每次寻宝可点 10 次。烧牌时有概率出现宝藏线索，前往正确地点有概率发现宝藏，宝藏几乎涵盖游戏内所有物品，甚至可能挖到贝壳。灵长目包括食人族、狐猴、洞魈、猩猩，远武、近武、投掷类均有效。

宝藏线索对应的藏宝地点：

| 线索 | 藏宝地点 |
|---|---|
| 山高岳小，水落石出 | 瀑布 |
| 水天一色，回头是岸 | 海岸 |
| 茂林深篁，一路向西 | 竹林 |
| 浅草丛生，蜂蝶乱舞 | 丘陵 |
| 薄命佳人，红荷菡萏 | 林中暗流 |
| 郁郁葱葱，战战兢兢 | 雨林 |
| 东西松柏，左右梧桐 | 松木林 |
| 飞沙走石，飞鸟不经 | 荒漠 |
| 乱云低暮，急舞回风 | 雪原 |

**玩法定位（攻略作者观点）**：闪避加成突出；寻宝属趣味玩法，不必刻意去挖。灵长目在造大船逃离过程中只可能面对狐猴、洞魈；只需点满核心技能灵巧即可玩。
