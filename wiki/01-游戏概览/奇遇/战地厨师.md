# 战地厨师

```wiki-infobox
归属角色 :: 罗兰
类型 :: 奇遇
```
- **归属角色**：罗兰
- **简介**：一次偶然的机会，罗兰接触到了《战就战》这款游戏，在这款公平竞技的游戏中领悟了「冲」和「屯」的战斗技巧。

| 技能 | 满级效果 |
|---|---|
| 强冲 | 冲的额外伤害提供 40 |
| 强屯 | 屯的额外命中提高 20% |
| 食肉 | 对食肉目动物伤害提高 50% |
| 双抗 | 中毒和眩晕抗性提高 30% |

> **提示**：强冲加上 0 级基础共 45 点，即第一下成功命中的近战伤害基础攻击力 +45；强屯 0 级数值未知。强冲与强屯在战斗中只能二选一。食肉目包括狼、熊、虎、狐狸、豹，远武、近武、投掷类均有效；逆境时近战的 50% 与 250% 做加法。食肉涵盖远山所有怪物种类，打远山更轻松。生存攻略总集将双抗记为「最高 40%」，与本文 30% 有出入（待考证）。

**玩法定位（攻略作者观点）**：为打挑战而生，双抗 + 屯在普通模式作用不大，狐狸是食肉目的的亮点；食肉 50% 伤害配合强冲打远山很好用；不氪金也能通过活动/书页获得。
