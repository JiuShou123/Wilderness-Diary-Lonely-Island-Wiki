# 元日食神

```wiki-infobox
归属角色 :: 小哥
类型 :: 奇遇
```
- **归属角色**：小哥
- **简介**：「野食小哥：有些猪，注定要留在回忆里。」体重与饥饿值变化会带来不同的额外属性。

| 技能 | 满级效果 |
|---|---|
| 食量 | 饥饿的阈值为 60/10 |
| 食欲 | 食欲引起的攻击力变化为 25% / −5% |
| 鱼纲 | 对鱼纲动物伤害提高 50% |
| 免伤 | 战斗中受到伤害降低 14.5% |

> **提示**：食量阈值为固定值（非百分比）。战斗中饥饿度 >60 时攻击力 +25%，<10 时 −5%，10–60（含端点）不增不减；对远武、近武、投掷类均有效，逆境时近战做加法。鱼纲包括食人鱼、吸血鬼鱼、剑吻鲨、大白鲨、未知生物、地下怪鱼。免伤计算在防御之前：先以怪物伤害 ×（100−14.5）%，再减去人物防御（含防具、果实、药丸、鱼等），结果向上取整。体重增减影响生命值：最高为标准值的 125%，最低为 75%，增减按生命值上限的千分比计算后直接在现有生命值上加减。改版后「体重减少增加闪避」的设定已取消。
