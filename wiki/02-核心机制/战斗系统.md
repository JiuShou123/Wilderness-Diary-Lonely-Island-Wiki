# 战斗系统

> 本页讲解《荒野日记：孤岛》的战斗流程、攻击距离与栈位、命中率影响因素、伤害计算公式，以及中毒、眩晕、击退、闪避、投掷、耐久、汲取等战斗机制。各武器的具体数值见[装备与武器](../03-物品/物品总览.md)，各生物的命中、闪避、攻速见[生物图鉴](../04-生物/生物总览.md)。

## 一、战斗基本流程

战斗为半自动进行：进入战斗后，人物与其装备的武器决定攻击距离与攻速，双方在各自射程内按攻速出手。

- **攻速**：数值越大出手越快。例如血匕攻速 2（全武器最快），石锤 0.8、重连弩 0.5（攻速慢）。挑战模式怪物亦有攻速属性，如狐狸、受伤的熊王、遗迹石像攻速为 2，猎豹与猩猩为 1.2，真鳄龟为 0.8。
- **攻击距离**：人物近武通常为 1～3，远武为 6～10，投掷武器为 3±1 或 3±2；绝大多数怪物攻击距离为 1。
- **移动**：当目标不在自身攻击范围内时，需要移动到射程内再攻击（据猩猩实战机制归纳；完整的行动力与回合细则资料未收录，待考证）。

> **提示**：战斗的胜负很大程度上取决于「武器攻击距离 × 命中率 × 伤害计算」三项，而非单纯的攻击力高低。远程与投掷武器适合对付高攻速或高闪避的敌人，近战武器则多在集火、控制等场景使用。

## 二、攻击距离与栈位机制

### 2.1 攻击距离

| 武器类型 | 攻击距离 | 说明 |
|---|---|---|
| 近战武器 | 1～3 | 多数为 1；竹枪、锋利竹枪、平底锅、女巫的扫帚、石锤为 2～3 |
| 远程武器 | 6～10 | 硬竹弩、重连弩为 10；机关连弩、伪袖珍手枪、燧发枪为 8；机关剑（远）、硬竹弓为 7；短弓、朱莉的长弓为 6 |
| 投掷武器 | 3±1 / 3±2 | 吹箭、雪球、小鞭炮、麻痹针、投掷飞刀为 3±1；竹筒炸药、毒液炸药、精致炸药、冰雪卷轴为 3±2 |
| 怪物 | 绝大多数为 1 | 挑战模式猩猩为唯一攻击距离超过 1 的怪物 |

### 2.2 猩猩的攻击距离特性

猩猩是挑战模式专属怪物，在雨林与原始森林中三只成群出现（详见[生物图鉴](../04-生物/生物总览.md)）。其关键特性：

- 猩猩攻击距离极大（相当于随身携带一把弓）。文档《猩猩》记为 **9**，图片《挑战模式生物属性图》记为 **8**，两处数据不一致（**待考证**）。
- 由于攻击距离足以打到玩家，猩猩在确定初始栈位后**不会再主动移动**；人物携带远武时，只要猩猩在远武射程内，人物也基本不会移动。因此杰克之刃等攻击距离为 1 的近武**打不到**猩猩。
- 猩猩栈位不确定、远武击退不稳定，二者都会影响主要依赖远武的打法。机关连弩容易把距离拉大而断箭，朱莉的长弓则容易把猩猩击退得过远，使石锤、女巫的扫帚等高攻击距离近武也够不到。
- 攻略作者认为较稳妥的搭配为「硬竹弓 + 毒竹枪」（无击退、可保持伤害）；高伤害加成奇遇可用「机关连弩 + 竹枪」，用竹枪把近处猩猩击退到外侧以缩短猩猩间距、避免断箭。（攻略作者观点）

### 2.3 初始栈位

- **初始栈位**指怪物出现时所站的位置。经比较分析，该栈位消耗 **1 点行动力**（据《猩猩》脚注）。
- 人物同样存在初始栈位，人物与怪物在各自栈位确定后，是否移动取决于对方是否在自身攻击范围内。

## 四、黑夜与照明

- **黑夜惩罚**：黑夜未携带火把或手电筒时，远程武器命中率 −30%（二喵）。
- **自带黑夜的地图**：溶洞、戈壁遗迹、黑暗囚室、洞窟、地底自带黑夜效果，且**不受「极昼」主题影响**（源君、雌犬）。
- **极昼**：一直判定为白天，没有黑夜，省火把、温度较高，但恢复生命值更困难。
- **极夜**：介绍为「一直判定为黑夜」，实际并非全黑，只是黑夜更长、白天仍有天亮阶段（据《于一数据库》）。
- **照明道具**：火把、小哥的手电均可减少夜间迷路与遭遇生物的概率（详见[物品图鉴](../03-物品/物品总览.md)）。

## 五、伤害计算

伤害公式转写自图片《伤害计算（朕将）》：

**总伤害 = 基础攻击 × 百分比攻击加成 × 波动加成 × 暴击加成**

### 5.1 基础攻击

`基础攻击 = 武器基础攻击 + 人物/奇遇定值攻击加成 + 果实/丸子加成 + 广告攻击加成`

| 来源 | 定值攻击加成 |
|---|---|
| 野食小哥吃东西 | +7 |
| 绝味小哥进攻 | +30 |
| 狂化战士狂暴 | +30 |
| 新春厨神老贝 | +25 |
| 战地厨师强冲 | +45 |
| 力大无穷 buff | +15 |
| 力量精准 buff | +8 |
| 广告 | +10 攻 |
| 肉粽 | +2 攻/个 |

（果实和丸子相同基础攻击的加成**不能叠加**。）

> **提示**：广告提供的 10 点基础攻击力与肉粽吃出的基础攻击力**不能加成给投掷类**；角色奇遇、鱼类、果实/药丸提供的基础攻击力**可以加成给炸药类**（源君）。

### 5.2 百分比攻击加成

`百分比攻击加成 = 100% + 天赋百分比攻击加成 + 奇遇百分比攻击加成`

| 来源 | 百分比加成 |
|---|---|
| 逆境 | +150% |
| 速泳 | +40% |
| 元日食神鱼纲 | +50% |
| 元日食神食欲 | +25% |
| 战地厨师食肉 | +50% |
| 双旦女爵爬行 | +50% |
| 不屈军魂偶蹄 | +50% |
| 夺宝怪盗灵长 | +50% |

### 5.3 波动加成

| 波动等级 | 波动范围 |
|---|---|
| 1 级 | 0.90～1.15 |
| 2 级 | 0.95～1.20 |
| 3 级 | 1.00～1.25 |
| 4 级 | 1.05～1.30 |

### 5.4 暴击加成与死基被动

- **暴击加成 = 1.5**（新春厨神为 1.75）。
- **死基被动**：百分比攻击加成公式为 `20% + 生存天数 × 1%`，属于特殊攻击加成，计算优先级位于百分比攻击加成之后，也可直接在总伤害上进行加成计算，无差别。

> **提示**：以上举例的加成均为最高值；怪物护甲及鱼类攻击 buff 影响不大，故公式转写时忽略不计（朕将）。

### 5.5 防御与免伤

**防御**在所有攻击加成计算完毕**之后**再做减法（《于一数据库》）。

**人物防御**（来自防具）：

| 防具 | 防御 |
|---|---|
| 旧棉衣 | 0 |
| 皮甲 | 5 |
| 防护服 | 5 |
| 羽毛裙 | 5 |
| 某人的新衣 | 7 |
| 老贝的草裙 | 5-8-10-12-15（可提升四次，初始 5，提升满 15） |
| 藤甲 | 10-14-18-22-25（可提升四次，初始 10，提升满 25） |

**怪物防御**：

| 怪物 | 防御 |
|---|---|
| 神秘遗迹与破风口遗迹的石像 | 10 |
| 食人族首领 | 5 |
| 机关甲人 | 5 |
| 机关甲兵 | 5 |
| 机关猛兽 | 3 |
| 真鳄龟 | 2 |
| 其他一般怪物 | 视为 0 |

> **提示**：**免伤**（人物免伤率）出现在怪物攻击公式中，但资料未收录人物免伤的获取来源与数值（**资料未收录**）。抗毒、抗晕属于状态抗性，不等同于免伤。

### 5.6 怪物实际属性公式

转写自图片《挑战模式生物属性图》（源君）：

- **生物实际血量 =（基础血量 × 天数系数 × 沉船系数）× 难度系数**（非沉船副本忽略沉船系数，公式括号不可拆）
- **生物实际攻击 = [（基础攻击 × 天数系数 × 沉船系数）× 难度系数] ×（1 − 人物免伤率）− 人物防御力**

| 系数 | 取值 |
|---|---|
| 挑战难度系数 | 1.3 / 1.7 / 2.2 / 2.6 / 3.1 / 3.5 / 4 / 4.6 / 5.3 / 6 / 7 / 8.1 / 9.2 / 10.4 / 11.6 |
| 天数系数 | 1-20d(1)；21-40d(1.1)；41-60d(1.15)；61-70d(1.2)；71-100d(1.25)……上限 1.4 |
| 沉船系数 | 1 / 1.2 / 1.3 / 1.5 / 1.6 / 1.7 / 1.8 / 1.9 / 2 / 2.1 / 2.2 / 2.3 / 2.4 / 2.4 / 2.5 / 2.7 / 3 / 3.3 / 3.3 / 3.3 / 3.6 / 3.6 / 3.8 / 4 |

## 六、会心一击与暴击几率

- **暴击几率**：《九条黑岩资料汇总》以「低/高」标注，满科技属性图则给出具体百分比（如匕首 35% 暴击、杰克之刃 100% 暴击），近战武器评价图称杰克之刃「满科技暴击率 95%」，三者口径不同（**待考证**）。
- **会心一击**：《九条黑岩资料汇总》「05 武器」表另列「会心一击」数值。由表内数据可见，会心一击数值约为基础攻击的 **1.5 倍**（如石斧 35→53、武士刀 60→90、燧发枪 120→180），与暴击加成 1.5 一致（**本文整理归纳**）。

| 状态 | 效果与来源 | 相关数值 |

| 中毒 | 毒竹枪、毒刃斧、短弓(毒)、硬竹弓(毒)、朱莉的长弓(毒)、硬竹弩(毒)、重连弩(毒)、毒羽箭、毒液炸药等使「敌中毒」 | 毒羽箭 40%、毒液炸药 90%、吹箭 55% 概率中毒 |
| 眩晕 | 石锤（敌硬直/75% 晕眩） | 麻痹针约 99.5% 晕眩/麻痹 |
| 击退 | 竹枪 40%、锋利竹枪 40%、女巫的扫帚 20%、驯兽鞭 20%、朱莉的长弓 40%、机关连弩 35%、重连弩 40%、伪袖珍手枪 40% | 数值取自满科技属性图 |
| 麻痹 | 麻痹针（范围麻痹），一次可制作三个 | 满科技表标约 99.5% 晕眩 |
| 硬直 / 冰冻 | 石锤（敌硬直）、寒羽箭（约 98% 冰冻）、冰雪卷轴（55% 冰冻），以及各冰属性短弓/硬竹弓/朱莉的长弓/硬竹弩/重连弩（敌硬直） | 数值取自满科技属性图 |

**挑战主题对状态的影响**（挑 1-3 起可出现，详见[挑战模式](挑战模式.md)）：

- **漫天金星**：所有敌人都有概率造成我方眩晕，熊、河马等重量级敌人概率更大。可用强身丸（抗晕 +15%）克制。
- **剧毒之心**：所有敌人都有概率造成我方中毒，毒蛇、毒蝎等本就有毒的敌人概率更大。毒攻击三次，每次损失本次判定时剩余生命值的十分之一。可用避毒丸（抗毒 +15%）克制。
- **背水一击**：敌人临死前有概率发动垂死一击，**无视距离、无视闪避**，并可与漫天金星/剧毒之心叠加出眩晕或中毒状态。
- **兽血沸腾**：敌人血量低于 25% 时攻击力提升 25%（相当于怪物带逆境者天赋）。

## 八、闪避机制

闪避加成来自以下来源（《于一数据库》8.3.3）：

| 来源 | 闪避加成 |
|---|---|
| 人物基础闪避 | 10% |
| 老贝的草裙 | 10%（闪避科技提升满后为 30%；满科技属性图标为 35%，口径不一致，待考证） |
| 空手道天赋 | 零星 20%，三星 35% |
| 绝味「回避」技能 | 20 级 25% |
| 宝基「灵巧」技能 | 20 级 14.5% |
| 基德烧牌「灵巧」 | 10% |
| 未知果实 / 女巫的药丸「灵巧」 | 10%（二者不叠加，任一吃出即可） |
| 开局广告 | 3% |
| 蝴蝶鱼 | 1%（攻略作者认为可能完全无效果） |

- 闪避**不需要**叠加到 100%。不同怪物命中不同，做到完全闪避所需的总闪避下限也不同。
- 背包负重低于 10 时「加闪避」的机制应当不存在（攻略作者观点）。
- 「人体描边」主题使敌人闪避 +15%，等效于降低我方命中。

> **提示**：完整闪避流（俗称「无敌流」）的条件较为苛刻：满闪草裙 + 三星空手道 + 灵巧技能 20 级的宝基，再烧牌出灵巧或吃果实/药丸出灵巧，即可全闪所有怪。除「背水一击」主题外难以被克制。

## 九、投掷武器机制

- 投掷武器基础命中 **100%**，且**不受人物精神影响**。
- 竹筒炸药有 **10% 哑火概率**；精致炸药「命中 Max」。
- 基础伤害（《于一数据库》8.5.1）：麻痹针 35、吹箭 35、投掷飞刀 50、毒液炸药 90、竹筒炸药 120、精致炸药 170。
- 攻击范围多为 3±1（吹箭、雪球、小鞭炮、麻痹针、投掷飞刀）或 3±2（竹筒炸药、毒液炸药、精致炸药、冰雪卷轴）。
- 投掷飞刀可回收（满科技表标 50% 回收、35% 暴击）。
- **攻击力加成规则**：广告的 10 点基础攻击力与肉粽的基础攻击力**不能**加成给投掷类；角色奇遇、鱼类、果实/药丸提供的基础攻击力**可以**加成给炸药类。
- 制作限制：精致炸药仅朱莉可制作；冰雪卷轴仅冰雪女王可制作；麻痹针一次可做三个。
- 实战评价：麻痹针的麻痹效果好；吹箭若未毒上偏弱；毒液炸药即使未毒上基础伤害也不错，且比吹箭更容易做出来（攻略作者观点）。

## 十、耐久机制

- 装备耐久**按种类计算**，不区分具体是哪一件：把快砍坏的斧头放进循环资源点，再从营地拿一把新的，也不会得到满耐久的新斧头。
- 「耐久的装备」与「普通的装备」不是同一类别，耐久度分别计算。
- 耐久消耗受天赋（如养护者）与挑战主题影响：「纵姿豪迈」主题使装备耐久消耗提升，带养护者对抗该主题不太现实（战斗天赋一般需带逆境者等）。
- 各武器的耐久数值见[装备与武器](../03-物品/物品总览.md)。

## 十一、汲取（吸血）机制

目前带吸血的武器有**武士刀、驯兽鞭、血匕**：

- 武士刀与驯兽鞭的「汲取」科技不建议点，点满也只吸 1 滴血。
- 血匕无科技强化提升，但固定每次吸血 **10 滴**，与打出多少伤害无关。
- 武器吸血只能弥补**本波战斗**中掉的血，不能回复以前掉的血；无论吸血发生在损血之前还是之后，都可回复本轮战斗的损血，战斗结束时统一结算。
- 不论敌人是何物种，都可以吸到血（石像、机关敌人等亦可）。

| 兽血乱炖 | +8 | 12 小时 |

- 未知果实与女巫的药丸若都吃出加温度，只有一个生效；兽血乱炖与小哥肉酱也只有一个生效。
- 温度叠加到一定程度后很难继续上升；以上数据以室外为准（排除营地温度影响）。
- 鳕鱼食用后 24 小时内不会因寒冷掉内伤，因此吃鳕鱼后无需再吃其他保暖食物，也不必生火。
- **寒霜时代**主题使温度比平时低 10℃；**极昼**下温度较高，**极夜**时较冷。

- 两地之间的距离估算括号中只显示鞋子的 −20%，不显示开局基础移动速度 +5%、骆驼 +10%，以及占星师、死基「死步」、兔基「移速蛋」等移动速度增加带来的时间缩短效果；但实际行走用时确实变短。
