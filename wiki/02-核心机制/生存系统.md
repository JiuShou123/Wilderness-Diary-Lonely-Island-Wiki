# 生存系统

> 本页讲解角色的六项状态、时间与季节、天气、温度、睡眠与恢复、意外事件等生存核心机制。玩家的最终目标是在生存中寻找[逃离方式](../01-游戏概览/逃离方式/逃离方式一览.md)，而生存系统的每一项状态都直接关系到能否活到逃离。

## 一、角色六项状态

角色共有六项状态（俗称「六围」为对应的上限属性，见[科技系统](科技系统.md)）：

| 状态 | 档位 | 主要下降原因 | 主要后果 |
|---|---|---|---|
| 外伤程度 | 健康 / 皮外伤 / 轻伤 / 重伤 / 血肉模糊 | 砍树、战斗掉血、副本剧情选择、食用部分鱼类（如岩鱼） | 达到皮外伤后可能引发内伤，程度越重内伤掉得越快 |
| 内伤程度 | 神清气爽 / 轻微不适 / 腹部胀痛 / 虚弱不堪 / 上吐下泻 | 外伤、饥饿、寒冷、副本剧情、部分鱼类（河豚、罗非鱼、三文鱼等） | 轻微不适起开始持续扣生命值，程度越重掉血越快 |
| 饥饿度 | 饱腹 / 轻度饥饿 / 饥饿 / 非常饿 / 饥肠辘辘 | 随时间持续下降 | 达到饥肠辘辘后开始掉内伤 |
| 精神状态 | 精神饱满 / 困乏 / 疲倦 / 非常疲倦 / 极度疲倦 | 随时间下降、工作与战斗消耗 | 影响命中率；极度疲倦时无法进行烹饪、制药、做工具、钓鱼等工作，战斗命中大幅下降 |
| 生命值 | 数值（上限受强健与天赋影响） | 战斗、内伤持续扣血、砍树自残等 | **生命值归零即死亡（唯一直接死因）** |
| 失眠值 | 轻松入睡 / 勉强入睡 / 夜不能寐 | 随时间下降（睡眠可恢复） | 失眠越严重，睡眠恢复的精神与生命值越少 |

> **提示**：除被直接打掉生命值或砍树自残外，生命值的减少大多由「内伤严重」引起；内伤又常常由「外伤、饥饿、寒冷」引起。因此状态管理的核心链条是：**防外伤 → 控内伤 → 保生命**。

### 1.1 各状态恢复方式

| 状态 | 常用恢复方式 |
|---|---|
| 外伤 | 绷带、膏药 |
| 内伤 | 汤药、药草（草药）、大补丸、条石鲷等 |
| 饥饿度 | 椰子、肉汤、烤肉、各类食物 |
| 失眠值 | 薄荷茶、青草膏（也可用蜂蜜等） |
| 精神 | 睡眠、石斑鱼、仙豆 |
| 生命值 | 睡眠、仙豆 |
| 温度 | 暖身丸、兽血乱炖、鳕鱼、玉米粥等（见下文温度小节） |

### 1.2 状态与睡觉恢复（机制细节）

- 睡眠恢复的血量与精神与**失眠值多少、床等级**挂钩：失眠值越高恢复越多；冥想等级越高，失眠值总量与「轻松入睡/勉强入睡」区间占比越大，恢复效果越好。
- 失眠值低时（夜不能寐）睡觉恢复量少；白天睡觉失眠值下降更快，精神饱满后再继续睡失眠值掉得也更快。
- 因此「生命值掉得多、精神没怎么掉」时较难通过睡眠恢复生命。
- 睡觉时间不同，失眠值降低与状态恢复效果不同（详见游戏内提示）；攻略作者建议分时段短睡（如 4 小时一觉）以提高恢复效率。

## 二、时间、季节与昼夜

- **时间**：游戏内时间流逝远快于现实；**24 小时 = 1 天**；**30 天 = 1 个季节**；游戏开局为**秋季**。
- **季节特性**：春天野怪血量提升；夏天温度高；冬天温度低。
- **昼夜**：夜间（天黑后）无照明会降低远程武器命中；部分地图（溶洞、戈壁遗迹、黑暗囚室、野人洞窟等）自带黑夜效果，不受「极昼」主题影响。
- **日记**：每天睡觉可写日记（心情笔记），成就系统中有「死亡笔记」等相关成就。

## 三、天气

- 游戏内天气包括：晴、多云、雾、雨、暴雨、雪、暴风雪等。
- 影响：
  - 恶劣天气影响命中；
  - 增加炸药哑火概率；
  - 额外降低建筑耐久（挑战主题「天气预报」下尤为明显）。
- 天气与部分资源联动：**海盐**只在晴天于海岸刷新（触发晒盐剧情后）。

> **提示**：攻略作者提示，在「天气预报」主题下，不急用的建筑尽量晚建晚升，避免建成即损耗。

## 四、温度

### 4.1 基础机制

- 温度显示在游戏界面时间右侧。
- 温度约低至 **-9℃** 左右开始持续降低内伤，温度越低内伤掉得越快。
- 高温不会造成内伤（实测）。

### 4.2 温度加成来源（以室外为准）

| 来源 | 加成 | 持续时间 |
|---|---|---|
| 皮甲 | +3℃ | 常驻（装备） |
| 旧棉衣 / 藤甲 / 羽毛裙 / 防护服 | +5℃ | 常驻（装备） |
| 未知果实 | +4℃ | 12 小时 |
| 女巫的药丸 | +4℃ | 12 小时 |
| 暖身丸 | +4℃ | 24 小时 |
| 玉米粥 | +4℃ | 12 小时 |
| 鳕鱼 | +5℃ | 24 小时（期间不会因寒冷掉内伤） |
| 兽血乱炖 | +8℃ | 12 小时 |
| 小哥肉酱 | +8℃ | 12 小时 |

> **注意**：
> 1. 未知果实与女巫的药丸若都提供温度加成，只有一个生效；兽血乱炖与小哥肉酱同理。
> 2. 温度叠加到一定程度后很难继续上升。
> 3. 鳕鱼食用后 24 小时内无需生火取暖，也无需再吃其他保暖食物。

### 4.3 七色圆球与温度

挑战玩法「七色圆球」（橙色圆球）要求达到 30℃ 整，需要利用衣物与食物精细调整温度，完整对照表见[进阶技巧](../06-攻略/进阶技巧.md)。

## 五、移动速度

- 两地之间的**预估行程时间不会显示**基础移速加成（如开局基础移速 +5%、骆驼 +10%、占星师/死基死步/兔基移速蛋等），只会显示鞋子的 -20%。
- 但实际行走时间会因这些加成而缩短。

移速加成来源（玩家整理）：

| 来源 | 效果 |
|---|---|
| 鞋子（背包） | 行程时间 -40%（界面显示 -20% 为估算口径差异） |
| 骆驼骑乘 | 基础移速 +10% |
| 占星师天赋 | +3% ~ +10%（随星级） |
| 异变死神「死步」 | 最高 +10% |
| 彩蛋兔爷移速蛋 | 详见[奇遇系统](../01-游戏概览/奇遇/奇遇一览.md) |

> 基础移速加成之间可叠加，攻略作者实测「骆驼 + 鞋子」合计约 +50%。

## 六、意外事件

### 6.1 夜袭

- 夜袭有两种：普通夜袭（图片为狼，俗称「卡车狼」）与**兽潮**（图片为熊）。前者游戏初期较少、后期约两天一次；兽潮第一次在第 8 天左右，之后每 20 天左右一次。
- 防御成功无损失；防御失败会损失**仓库与暂存点**的物资（背包物资不会丢），并损失建筑耐久。暂存点丢失内容不提示。
- 部分特殊道具不会被偷（物品资料无删除选项者，如珍珠、油料、七色圆球、荒野秘宝、绳索、海盗船、特殊的帆布、铁锭、石板、背鳍、研究资料、研究员服装、木耳汤食谱、弹药制造图纸等）。
- **防夜袭手段**：
  - 装备夜语者天赋、建造/升级栅栏；
  - 保留至少一次「防狼广告」：遇袭时会出现「确定 / 看广告抵挡」的选择，此时可直接关游戏重进避免损失；
  - **白狼守家**：忠诚度 ≥ 60、饥饿度 ≥ 30、生命值 > 0 时必定防御成功（每次防御后忠诚度 -35）。白狼饥饿度每小时 -3（每天 -72），建议临近 0 点前喂食；
  - 月圆之夜主题会提高夜袭概率。

### 6.2 兽潮防御小游戏

- 遇到兽潮需点击「开始防御」，点击「取消防御」直接判定失败。
- 规则：我方人物可在九宫格阴影范围内移动（可斜向移动，「驻守」为原地放弃一回合）；野兽只能横/竖移动，越过我方后直冲营地。
- 防线判定：无栅栏时相当于 2 把双刃斧（2 条命），放走 2 只野兽即失败；栅栏每升一级 +1 把双刃斧，高级栅栏共 5 条命。
- 剩余双刃斧百分比越高，防御成功后**兽穴**物资越多；兽穴存在 4 天，需及时采集（背包满时继续拾取反而会丢失背包物资）。
- 攻略技巧（玩家经验）：
  - 不自信可在断网状态防御，成功联网、失败关游戏；
  - 放弃第 8 天竹林兽穴不去采集，可让 20+ 天兽潮的丘陵兽穴按竹林兽潮的结果生成（必定拿到兽皮、草药、兽血、蜂蜜等）。

### 6.3 路袭（赶路遇怪）

- 赶路（尤其夜路）可能遭遇野兽。
- 不想打可关游戏重进，一般不再遇怪（注意：重进后仍在出发地，但时间已流逝到遇怪时点）。
- 也可断网战斗：打过联网；死亡或掉血过多则关游戏重连。

### 6.4 遗物与遗言

- 每次新开局有机会捡到「藤条哥」的遗体，获得若干藤条。
- 可捡到其他玩家的遗物、看到遗言；拾取需要预留负重（按未点「轻便」的重量计算）。
- 自己死亡时可留下遗物与遗言。
- 关卡中战斗或采集后也可能发现其他玩家的遗言。

### 6.5 意外事件广告

- 有广告版本赶路时可能遇到意外事件，看广告获得物资（每天 3 次，现实时间 8 点刷新；0 点在线福利也会刷新）。
- 奖励从石片、草药、椰子、烤肉、肉汤、绷带、青草膏、双刃斧、竹枪等物资中随机获得三种，每种 1 个。

## 七、死亡与复活

- 死亡判定：**生命值归零**即死亡（饿死、冻死、内伤致死、战斗死亡均由此触发）。
- 死亡后可选择复活（消耗复活资源）或「重新开始」；复活机制与成本详见[账号资源系统](../07-收集/账号资源系统.md)。
- 死亡后还会进入「遗物/遗言」流程，并可从主页读取上一处[存档点](../08-附录/资料来源.md)（崖洞/神秘遗迹）。

## 八、过冬与生存要点（攻略作者观点）

- 冬天温度低（最冷约 50~55 天区间，极限低温可达 -30℃ 级），建议：提前推图至雨林、囤积大量木材与草药、每日出门携带 4~6 个草药防内伤、在家烧木炭生火取暖。
- 极端低温（-50~-55）时尽量不出门；实在需要出门可穿藤甲、食用鳕鱼/兽血乱炖等保暖食物。
- 新人若有条件，优先保证「一天一餐 + 保暖 + 内伤药储备」的循环。
