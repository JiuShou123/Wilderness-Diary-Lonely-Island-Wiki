# 黑暗囚室推箱子

### 规则

- 左边从上到下依次是太阳、飞鸟、人像、蛮鱼，目标是把它们按从上到下的顺序移到右边去。
- 挪动过程中，每一步都要求上面的图像可以被放在本来位置在它下面的任何一个图像的上面，不能被放在本来位置在它下面的任何一个图像的下面。
- 只有处在某一列最上面的图像（没有被其他图像压着）才可以被挪动。点击某个可挪动的图像，再点击它要去的位置，即可挪动。

### 解法步骤

```
太阳去中间列，飞鸟去右边列，太阳去右边列放在飞鸟上，人像去中间列，太阳去左边列放在蛮鱼上，飞鸟去中间列放在人像上，太阳去中间列放在飞鸟上，蛮鱼去右边列（蛮鱼就位），太阳去右边列放在蛮鱼上，飞鸟去左边列，太阳去左边列放在飞鸟上，人像去右边列放在蛮鱼上（人像就位），太阳去中间列，飞鸟去右边列放在人像上（飞鸟就位），太阳去右边列放在飞鸟上（太阳就位）。
```

简化为「石板编号 + 目标列」记法（第一列/第二列/第三列）：

```
太阳2 鸟3 太阳3 人2 太阳1 鸟2 太阳2 鱼3 太阳3 鸟1 太阳1 人3 太阳2 鸟3 太阳3
```

> **提示**：理解规则后并不难，小学数学有所涉猎。偶数个图像（或数字等）按此规则在左中右三列中挪动时，最上面的先去中转列，次上的去目标列；奇数个的话，最上面的直接去目标列，次上的去中转列。
