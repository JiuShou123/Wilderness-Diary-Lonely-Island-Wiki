# 逆境者

```wiki-infobox
类别 :: 战斗天赋
星级 :: 零星 / 一星 / 二星 / 三星
```
## 效果数据

| 星级 | 效果 |
|---|---|
| 零星 | 生命值低于 20% 时近战攻击力提升至 1.8 倍 |
| 一星 | 低于 25% 提升至 2 倍 |
| 二星 | 低于 30% 提升至 2.3 倍 |
| 三星 | 低于 35% 提升至 2.5 倍 |

## 获取与升星

- 获取：商店购买 / 神秘人抽奖 / 限时天赋包（见 [天赋一览](天赋一览.md)）
- 升星消耗见 [天赋一览](天赋一览.md) 的升星规则
