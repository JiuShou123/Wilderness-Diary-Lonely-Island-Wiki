## 三、计算公式

- **生物实际血量 = （基础血量 × 天数系数 × 沉船系数）× 难度系数**　注：非沉船副本忽略沉船系数，公式括号不可拆
- **生物实际攻击 = [（基础攻击 × 天数系数 × 沉船系数）× 难度系数] ×（1 − 人物免伤率）− 人物防御力**　注：同上

### 系数表

- 挑战难度系数依次为：1.3 / 1.7 / 2.2 / 2.6 / 3.1 / 3.5 / 4 / 4.6 / 5.3 / 6 / 7 / 8.1 / 9.2 / 10.4 / 11.6
- 天数系数：1-20d（1）；21-40d（1.1）；41-60d（1.15）；61-70d（1.2）；71-100d（1.25）……（后续不列出，上限为1.4）
- 沉船系数：1 / 1.2 / 1.3 / 1.5 / 1.6 / 1.7 / 1.8 / 1.9 / 2 / 2.1 / 2.2 / 2.3 / 2.4 / 2.4 / 2.5 / 2.7 / 3 / 3.3 / 3.3 / 3.3 / 3.6 / 3.6 / 3.8 / 4
