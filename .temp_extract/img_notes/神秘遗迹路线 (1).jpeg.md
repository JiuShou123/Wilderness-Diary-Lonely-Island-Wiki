## 路线流程

起点：**神秘遗迹**（分为两条主分支）

### 分支一：太阳之门

```
太阳之门
 └─ 箱子
     └─ 遗迹孤狼
         ├─（谨慎通过 → 获得珍珠）[十珍珠]
         ├─（尝试接触 → 获得硫磺）[十硫磺]
         ├─ 继续前进
         │   └─ 遗迹孤狼（硫磺）
         │       └─ 遗迹孤狼（子弹）
         │           └─ 太阳之门
         │               └─ 蝙蝠王后（图纸）
         └─ 休息整顿
             └─ 掉落危桥
                 └─ 是否点燃火把
                     ├─ 是 → 地下怪鱼 [十珍珠，四硝石]
                     └─ 否 → 未知生物
```

- 太阳之门左侧分支标注：**十珍珠**
- 尝试接触分支标注：**十硫磺**
- 继续前进路径旁标注：硫磺、子弹、图纸
- 是否点燃火把 → 是 的分支标注：**十珍珠，四硝石**

### 分支二：月亮之门

```
月亮之门
 └─ 箱子
     └─ 遗迹孤狼 [十珍珠]
         ├─ 跟随流动 →（向左回到太阳之门分支）
         └─ 找其他路
             └─ 未知石室：飞鸟图腾—人像图腾—蛮龟图腾
                 ├─ 打开大门
                 │   └─ 带匕首
                 │       └─ 吸血蝠王
                 │           └─ 离开神殿
                 └─ 四处查看—机关
                     ├─ 逆时针 → 月亮大门
                     └─ 顺时针 → 太阳大门

月亮大门 → 吸血蝠王
太阳大门 → 蝙蝠王后
蝙蝠王后 → 离开神殿
```

### 汇聚点

两条分支最终都通往 **离开神殿**。
