# NPC系统

> 本页收录《荒野日记：孤岛》中母狼栖息地、骆驼栖息地、野蛮人居住地等 NPC 的开启条件、好感度机制、可交易物品与价格，以及金雕、神秘人、机关甲人的玩法数据。

## 概述

游戏中可长期互动的 NPC 主要有母狼（白狼）、骆驼、野蛮人（土著）、金雕、神秘人、机关甲人。其中白狼、骆驼、野蛮人通过推图进度与游戏天数解锁，靠好感度换取功能与物资；金雕、神秘人、机关甲人则是账号级玩法，其羁绊、活力值、抽奖与组件等级数据在重开新局后不会清零。

> **提示**：本页涉及数据除特别说明外，均以普通模式为准；涉及挑战模式差异处会单独标注。

## 一、白狼

### 获取条件

- 打完湖泊且游戏时间第 10 天，母狼上门索要 2 个生肉后，出现母狼栖息地。
- 母狼好感度达到 4.5 心，可赠予玩家一只白狼。
- 白狼获得后自动参战，无法丢弃；获得后可建造宠物室以恢复其状态。

### 三大属性

白狼拥有饥饿度、忠诚度、生命值三个状态。

| 状态 | 上限 | 机制 | 恢复方式 |
| --- | --- | --- | --- |
| 饥饿度 | 100 | 低于 30 时无法出战；每小时下降 3 点，即每 20 分钟下降 1 点 | 2 生肉喂食一次，恢复 80 |
| 忠诚度 | 100 | 影响攻击力，但不影响出战（忠诚度 0 也可参与普通战斗）；白狼参与夜袭防御需忠诚度 ≥ 60；生命值每减少约 8 点，忠诚度下降 1 点 | 1 宠物口粮驯养一次，恢复 80 |
| 生命值 | 246 | 为 0 时退出战斗 | 1 草药治疗一次，恢复 80 |

> **提示**：《新人常见问题解答》中记载饥饿度低于 20 时无法出战，与本页所采主要来源（低于 30）不一，存疑处待考证。

白狼忠诚度对攻击力的影响如下（攻击力为五个档位，各档对应的忠诚度范围不保证精确）：

| 忠诚度 | 攻击力 |
| --- | --- |
| 0-20 | 15 |
| 21-40 | 22 |
| 41-65 | 30 |
| 66-90 | 37 |
| 91-100 | 45 |

### 宠物室

获得白狼后可在家建造宠物室，用于恢复白狼的饥饿度、忠诚度、生命值。宠物室有耐久度，损坏后需要修理。

### 守夜机制

- 白狼忠诚度 ≥ 60、饥饿度 ≥ 30、生命值 > 0 时，必定防御夜袭成功；靠白狼防御一次夜袭，忠诚度会下降 35 点。
- 判定所依据的饥饿度不是点击睡觉那一瞬间的数值，而是遇到夜袭时的数值。夜袭并非固定在 0 点，若选择睡到天亮，则夜袭判定发生在 6 点。白狼饥饿度每小时下降 3 点，即每天下降 72 点，因此睡到天亮时饥饿度往往低于 30，宜在接近 0 点时喂食。

### 好感度各阶段所需物资

| 阶段 | 所需物资 |
| --- | --- |
| 触发时（首次上门） | 生肉 2 |
| 0.5→1 | 生肉 2 |
| 1→1.5 | 藤条 2 |
| 1.5→2 | 藤条 2 |
| 2→2.5 | 草药 2 |
| 2.5→3 | 草药 4 |
| 3→3.5 | 生肉 2 |
| 3.5→4 | 生肉 4 |
| 4→4.5 | 生肉 4 |
| 4.5→5 | 秘制炖肉 1 |

- 快捷方式（刷满 4.5 心）：生肉 12（不含上门索要的 2 个）+ 草药 6 + 藤条 4，可顺便带上与母狼换宠物口粮所需的生肉。
- 4→4.5 半心也可用「等母狼上门索要 4 个淡水」的方式推进；装备万人迷天赋时拒绝它不会掉好感度。4.5 心后 4 个生肉又能从 4 心升回 4.5 心。
- 只有罗兰角色可以制作秘制炖肉；其他角色可通过邮箱转盘奖励获得。

### 上门送物与投食

- 每提升一次好感度，若耐心等待，母狼都会上门送东西。4.5 心前送出的有石块+木材、石片+铁矿、木炭+黏土、人参等。
- 4.5 心与 5 心时送出的东西有机会收到：宠物口粮 2，或木炭 4 + 软金 4。送出的物资可被万人迷天赋翻倍。
- 4.5 心后，游戏时间每天可使用 5 生肉投食，与母狼换 1 个宠物口粮，并有概率获得其他资源（石块、铁矿、薄荷、竹子、兽皮、兽筋等），可被万人迷天赋翻倍。投食于游戏时间每天 0 点刷新。

## 二、骆驼

### 获取与骑乘

- 打完绿洲且游戏时间第 20 天，骆驼上门索要 2 个草药后，出现骆驼栖息地。
- 好感度达 5 心可以骑乘，增加基础移动速度 10%。
- 骑乘后人物头像上会出现骆驼图标；骑乘后不需要喂养照顾，也无法进行互动。

> **提示**：骆驼增加 10% 移动速度，鞋子增加 40% 移动速度，两者叠加为 50%。

### 好感度各阶段所需物资

| 阶段 | 所需物资 |
| --- | --- |
| 触发时（首次上门） | 草药 2 |
| 0.5→1 | 草药 2 |
| 1→1.5 | 椰子 2 |
| 1.5→2 | 椰子 2 |
| 2→2.5 | 淡水 4 |
| 2.5→3 | 淡水 4 |
| 3→3.5 | 薄荷 4 |
| 3.5→4 | 薄荷 4 |
| 4→4.5 | 土豆 4 |
| 4.5→5 | 土豆 8 |

- 快捷方式（刷满 5 心）：草药 4（去掉上门索要的 2 个，只需带 2 个）+ 椰子 4 + 淡水 8 + 薄荷 8 + 土豆 12。
- 若在骆驼上门前装备三星万人迷，给了上门索要的草药 2 后，只需带淡水 4 + 薄荷 8 + 土豆 12。

## 三、野蛮人（土著）

### 获取条件

- 打完远山且游戏时间第 20 天，野蛮人上门索要 1 个绷带后，出现野蛮人居住地。
- 首次上门不给，之后再补需要给双份（即 2 个绷带）。白狼、骆驼上门索要时拒绝则无需双份赔礼。

### 好感度各阶段所需物资

| 阶段 | 所需物资 |
| --- | --- |
| 触发时（首次上门） | 绷带 1 |
| 0.5→1 | 珍珠 3 |
| 1→1.5 | 汤药 2 |
| 1.5→2 | 薄荷茶 2 |
| 2→2.5 | 珍珠 6 |
| 2.5→3 | 薄荷茶 4 |
| 3→3.5 | 蜂蜜 4 |
| 3.5→4 | 蜂蜜 4 |
| 4→4.5 | 皮甲 4 |
| 4.5→5 | 珍珠 10 |

- 快捷方式（刷满 5 心）：绷带 1（上门索要，无需另带）+ 汤药 2 + 薄荷茶 6 + 蜂蜜 8 + 皮甲 4 + 珍珠 19。
- 三星万人迷可使野蛮人的初始好感度达到 2 心，上门索要的仍是 1 个绷带，给后好感度达 2.5 心；此时除上门索要的绷带 1，只需给薄荷茶 4 + 蜂蜜 8 + 皮甲 4 + 珍珠 10。
- 进入第 20 天 0 点时不要在营地：否则野蛮人会在玩家尚未装备三星万人迷时上门，初始好感度为 0 心，需要给他的珍珠就是 19 颗。建议第 19 天晚上出门，过 0 点装备万人迷再回营地，并记得备好绷带。

### 野蛮人处新增可交易物品（好感度分级）

好感度每增加半心，当日提供的所有可交易物品数量都会刷满；可交易物品于游戏时间每天 0 点刷新。

| 好感度 | 解锁交易项 |
| --- | --- |
| 0 | 石块 4、石片 5 |
| 0.5 | 无 |
| 1 | 铁矿 2 |
| 1.5 | 无 |
| 2 | 黏土 4、软金 2 |
| 2.5 | 无 |
| 3 | 双刃斧 1 |
| 3.5 | 土豆酒 1 |
| 4 | 硝石 2 |
| 4.5 | 无 |
| 5 | 硫磺 2；结实的木材 2（武斗或智斗成功的情况下） |

> **提示**：最后给他 10 颗珍珠升满好感度时，「给他」不要点太快，点太快会点到武斗上去。

### 武斗与智斗

- 武斗：需击败三个食人族首领，一般不建议尝试（闪避流「宝基」不用烧牌即可闪避食人族）。武斗被打死时，花复活包或贝壳复活即算成功。
- 智斗：拼图（八数码），需在 100 步以内拼出。详见 [小游戏攻略](../04-攻略指南/小游戏攻略.md)。

### 五星攻略（珍珠的节流与开源）

野蛮人好感度 5 心后，会持续索要藤甲；若未装备万人迷天赋，不给会掉好感度。若不需要和他换硫磺，掉好感度也没有关系；若是造大船逃离，武斗或智斗成功后，即使拒绝给藤甲导致好感度下降，仍可每天去领结实的木材。

珍珠不足的两种解决思路：

**节流（不给珍珠，等他上门要其他物品代替）：**

| 缺口 | 做法 |
| --- | --- |
| 差 ≤3 个 | 上门要绷带给他后，等他上门要其他东西代替珍珠 3（据记为上门索要绷带 1） |
| 差 ≤6 个 | 上门要绷带给他后，主动送去珍珠 3、汤药 2、薄荷茶 2，等他上门要东西代替珍珠 6（据记为上门索要汤药） |
| 差 ≤10 个 | 上门要绷带给他后，主动送去珍珠 9、汤药 2、薄荷茶 6、蜂蜜 8、皮甲 4，等他上门要藤甲代替珍珠 10；给了藤甲后在营地直接进行武斗或智斗 |

- 做藤甲所需的 8 个羊毛：普通模式可打雪原前两波获取；挑战模式注意雪原第二波羊是在几波狼之后。神秘遗迹一进门可采集到 12 草药和 4 羊毛，可用清扫者断网刷双倍。

**开源（主动获取珍珠）：**

- 湖泊给 12 个，戈壁遗迹给 18 个（一般不会为拿珍珠打戈壁遗迹）。
- 用生肉钓食人鱼，打败后获得 1 个珍珠；沉船箱子概率开出珍珠（沉船可断网打）。
- 沉船一侧较稳定：右分支「甲板中东阶梯 → 研究房 → 研究房北阶梯」这个小地图的箱子里有 2-3 个珍珠；右分支更近一个小地图。带清扫者天赋时可断网刷双倍，即每个箱子可得 4 个或 6 个珍珠。
- 神秘遗迹：想一次拿满 20 个，在不触发清扫者的情况下应选月亮之门。

### 祭品与不明棱梭

- 祭品：野人赠送（看脸）。野蛮人 4.5 星及以上时持续和他交易会送祭品，祭品相当于崖洞的绳索，用于打开神秘遗迹。
- 不明棱梭：进入神秘遗迹的门票（也可用荒野秘宝代替）。一般是野蛮人好感度满并达到一定天数后才给，4.5 心好感度时也给过。一般为 1 个，可能因天赋影响额外获得 1 个。

> **提示**：绳索打通溶洞得 1 根，打完远山和戈壁遗迹也可各采集得 1 根。

## 五、金雕

### 获取与羁绊

- 第一次打乱石林会获得金雕，获得时可为其起名。获得后要经历「健康成长」「别离之时」「归来之时」几个剧情，屏幕左边会出现一根树枝，点开即可看到金雕，可随时改名。
- 获得过金雕后，每次新开局出门逛两圈回营地即可触发「恍若隔世」剧情，树枝与金雕出现，金雕收集物资的时间开始计时。
- 喂养、嬉戏均可增加羁绊，现实时间的流逝也能增加羁绊。

金雕的羁绊与对应活力值上限：

| 羁绊 | 活力值上限 |
| --- | --- |
| 破壳 | 115 |
| 绒羽 | 130 |
| 针羽 | 145 |
| 正羽 | 160 |
| 跳枝 | 175 |
| 扑草 | 190 |
| 齐羽 | 205 |
| 振翅 | 220 |
| 丰羽 | 235 |
| 羽化 | 250 |

- 羁绊到达羽化后不能再提升。

### 活力值与收集物资

- 最短现实时间 1 小时金雕收集一次物资。时间到后，从外面回到营地，或在营地重新登录，金雕才会出现。
- 金雕活力值每小时消耗 5 点，即每 12 分钟消耗 1 点，每次收集物资归来时结算。可看广告双倍领取，双倍领取不消耗额外活力值。
- 活力值越多，能收集物资的时间越长，收集到的数量越多。活力值只有 10 时，再长时间不上线，上线也只能领到一小时的物资。
- 可收集物资包括未知果实、藤条、草药、生肉、黏土、硝石、软金、硫磺、羊毛、珍珠等，最少 2 个未知果实保底。物资种类与地图开启程度有关（如只打完海岸开启竹林，只能收集藤条、草药、生肉、未知果实）。
- 金雕的羁绊和活力值为账号级数据，羁绊没满时，逃离前若有宠物口粮，可和金雕嬉戏用掉并驯养满活力值。

### 驯养与互动

- 驯养：用 1 个宠物口粮驯养一次加 50 点活力值。
- 嬉戏：一次消耗 20 点活力值，活力值低于 20 无法嬉戏；金雕活力值不会低于 10。故嬉戏到 10 点后，驯养一次加到 60，可再嬉戏三次。
- 在外遇到问玩家要生肉吃的金雕是别人家的，据说喂了能加羁绊；无论喂还是拒绝，记得关闭该界面，否则在关卡中不能点头像打开背包。

> **提示**：据玩家源君统计，金雕叼回物品与游戏天数相关：2-19 天为藤蔓；20-29 天为黏土、软金；30+150x 至 59+150x 天为羊毛；60+150x 至 179+150x 天为珍珠、硫磺、硝石（x 取 0、1、2……依次循环）。（攻略作者观点，待考证）

## 六、神秘人

- 瀑布通关后解锁神秘人。
- 玩法：在他处用贝壳购买小袋粗粮，每次购买会让玩家在其库存中抽取一样作为礼物带走。
- 单抽消耗 600 贝壳，十连抽消耗 5400 贝壳；购买十次必得天赋或图纸或求生精选。
- 抽奖获得的补给发放至邮箱（转盘奖励）；部分奖励直接与账号绑定。

神秘人抽奖奖励：

| --- | --- |

## 七、机关甲人

### 获取与组件机制

- 机关甲人第一次从溶洞离开时获得，获得后每次开局直接拥有。
- 组件属性为账号级数据，重新开局不会变化，分为四类：

| 组件 | 作用 |
| --- | --- |
| 头部核心 | 目前只有采集核心，且不能升级 |
| 足部组件 | 决定机关甲人完成采集内容所需达成的条件，升级后降低条件要求 |
| 躯干组件 | 决定可累积的奖励次数，达到当前累计次数上限后不再累计，升级后提高可累积次数 |
| 手臂组件 | 决定可采集的资源类型，升级后单次获得的资源数量和种类增加 |

- 界面还包含神秘匣子与机甲制作台。
- 每次开局第一件事：向左转，点击机关甲人，让「时光之足」开始计时。

### 神秘匣子

- 用神秘钥匙抽奖：消耗 1 把启动一次，消耗 9 把启动十次；十连抽保底出现至少一个组件配方。
- 神秘钥匙主要通过「活着真好」和「贝壳狂欢」获得（活着真好奖励可看广告双倍领取，贝壳狂欢奖励只能直接领取）。
- 可抽取机关甲人各种组件配方及其他补给品：所有配方综合抽取概率 30.67%，其他补给品综合抽取概率 69.33%。
- 重复获得的配方自动转化为对应配方的升级经验，满足当前经验等级自动升级。配方升级后若组件已制作出来，属性会相应增长，无需重新制作。
- 补给品发放至邮箱（神秘匣子奖励）。

补给品包括：草药 15、人参 5、藤条 15、石片 10、硫磺 10、硝石 10、软金 8、暖身丸 8、强身丸 8、避毒丸 8、军粮丸 8、木耳汤 8、圣诞蛋糕 8、圣诞布丁 8、熏火腿 8、玉米粥 8、拐棍糖 8、旧棉衣 1、防护服 1、羽毛裙 1、某人的新衣 1、伪袖珍手枪 1、机关连弩 1、机关剑 1、改良的平底锅 1、女巫扫帚 1、驯兽鞭 1、石锤 1、血匕 1、杰克之刃 1、麻痹针 10、吹箭 10、寒羽箭 10、宠物口粮 5、仙豆 1 等。
