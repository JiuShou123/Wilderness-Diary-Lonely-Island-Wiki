# 新手指南

> 面向首次接触《荒野日记：孤岛》的玩家，概述游戏目标与基本流程，整理常见问题问答，并给出推图、资源、建造、过冬与逃离方式的选择建议。

> **说明**：本页除特别标注外，数据以普通模式为准；挑战模式专属内容另行注明。

## 一、游戏目标与基本流程

《荒野日记：孤岛》是一款文字类生存游戏。玩家需要在孤岛上收集物资、维持生存，并寻找逃离孤岛的方法。

- **胜利条件**：逃离孤岛即算游戏胜利。
- **失败条件**：在逃离过程中死亡即算游戏失败。
- **基本循环**：外出探索地图、采集资源与狩猎 → 回营地建造与制造 → 提升状态与科技 → 推进主线并最终解锁一种逃离方式。

### 1.1 六项状态与温度

| 状态 | 说明 |
|---|---|
| 外伤 | 外伤减少严重会导致内伤加重 |
| 内伤 | 内伤严重会导致血量迅速下降 |
| 饥饿度 | 持续降低，饥饿严重会导致内伤降低 |
| 精神 | 影响命中率，且精神过低时不能工作 |
| 生命值 | 生命值为 0 时死亡 |
| 失眠值 | 持续降低，失眠严重会导致睡觉补充的状态减少 |
| 温度 | 显示在时间右侧，温度到达一定值时开始掉内伤 |

常用恢复方式：

| 状态 | 常用恢复方式 |
|---|---|
| 外伤 | 绷带、膏药 |
| 内伤 | 汤药、草药 |
| 饥饿度 | 椰子、肉汤 |
| 失眠值 | 薄荷茶、青草膏 |
| 精神 | 睡眠、石斑鱼、仙豆 |
| 生命值 | 睡眠、仙豆 |
| 温度 | 暖身丸、兽血乱炖 |

### 1.2 基础设定

| 设定 | 说明 |
|---|---|
| 时间 | 时间逐渐消逝，比现实一天快得多；不同时间睡眠会导致失眠值与状态恢复不同 |
| 天气 | 雾天、晴天、雪天等，会影响人物命中、建筑耐久等 |
| 天数 | 24 小时即一天 |
| 季节 | 30 天即一个季节，游戏开始为秋季 |

季节影响：春天野怪血量提升，夏天温度高，冬天温度低。

### 2.1 互赠包类型

| 包类型 | 开启可获得 |
|---|---|
| 材 | 材料，如石片 |
| 医 | 药品，如青草膏 |
| 食 | 食品，如仙豆 |
| 近武 | 近战武器和弓箭，如石锤、寒羽箭 |
| 远武 | 远程武器，如重连弩 |

> **提示**（攻略作者观点）：互赠有两个可提升效率的技巧——①断网开包，开到想要的再联网，没开到想要的退出去联网重进；②赠送时输入 uid 完毕之后迅速点多次赠送按钮，这样包会多给。

### 2.2 黑暗囚室解法

左边 4 个方块，从上至下依次是：太阳、鸟、人、鱼。游戏目的是将最左边这一列方块依次移动至最右边，每次只能移动一块；从左至右是第一列、第二列、第三列。

「太阳 2」的意思是：点击太阳石板，再点击第二列，将太阳石板移动至第二列。

解法顺序：太阳 2 → 鸟 3 → 太阳 3 → 人 2 → 太阳 1 → 鸟 2 → 太阳 2 → 鱼 3 → 太阳 3 → 鸟 1 → 太阳 1 → 人 3 → 太阳 2 → 鸟 3 → 太阳 3。

## 三、推荐推图路线

新人通用推图路线（来自新人 FAQ）：

> 乱石林 → 瀑布 → 灌木丛 → 海岸 → 竹林 → 丘陵 → 溶洞 → 暗流 → 湖泊 → 沼泽 → 火山 → 森林 → 远山 → 荒漠 → 雪原前两波 → 绿洲

低挑（挑战 1-4）开局推图路线（攻略作者观点，来自低挑专题）：

> 乱石林 → 瀑布 → 海岸（开图出去前携带 3 个木头，在瀑布做陷阱拿鱼）→ 灌木丛 → 竹林

低挑路线要点（攻略作者观点）：

- 竹林是第一个难点，野猪命中高，而伤害较低时没有兽皮做皮甲，需慢慢开荒；正常开局约第二次可打完竹林，其中把猪杀光。
- 不能太浪，半血主动退走，不要硬顶野猪（床一次最多只能回半血），需保证每次出门都处于优秀状态。
- 丘陵与溶洞阶段，竹枪的适用范围更强，并有机会遇到隐藏副本。丘陵熊王副本必然要打，是稳定的兽皮出产点；溶洞蛇王收益太低（只给铁锭），没必要可以跳过。
- 约第 7、8 天进入低挑难点：远山狐狸、暗流野猪、湖泊河马。低挑最重要的是不能卡血，半血就走。

资源之间的关系：

- 藤蔓越多，薄荷长得越慢。
- 野猪越多，竹子长得越慢。
- 熊越多，蜂蜜长得越慢；蜂蜜越多，草药长得越快。
- 毒蛇越多，乔木长得越快；乔木长得越快，毒蛇长得越慢。

### 4.2 局外资源

局外资源指单局之外的物资，如贝壳、书页、原石。新人局外资源十分有限，需提高利用率。

**贝壳**

- 获取：做活动和成就获得，看广告也会有。
- 优先购买顺序：先买背包和鞋，之后选择人物购买，局内资源包尽量别买。
- 商店出售的天赋都可以买，优先清扫者、万人迷。
- 神秘人免费抽奖一般是资源；若想十连抽最好准备 6000 贝壳，可抽 11 次并领取活动内 6000 贝壳返利。
- 普通模式栅栏包和武器包不需要买。
- 要学会屯贝壳，不要因失误死亡后反复复活而导致贝壳不足。

**书页**

- 获取：主要通过活动和挑战任务获取，看广告也有；武器和人物科技都需要书页提升。
- 性价比较高的武器提升是箭矢和双刃斧。
- 对于波动，要么 0 级要么直接点满，波动不到 3 级会降低伤害。
- 先提升原皮属性和奇遇核心技能。
- 原皮可以将外伤和饥饿放到最后加点，内伤、血量、失眠、精神优先。

**原石**

- 获取：主要通过挑战任务获得；挑 11 的日常任务才会有结晶。
- 很多天赋到了三星会质变，如空手道和逆境者（逆境在 0 星时效果不佳）。
- 优先提升核心天赋：万人迷、强攻流的逆境、闪避流的空手道。

### 4.3 开局准备

**版本选择**

| 版本类型 | 说明 |
|---|---|
| 无广告版（4399、华为、小米等） | 不推荐。福利贝壳、神秘人转盘奖励、神秘钥匙等获取极慢，夜袭防御是大问题 |
| 有广告版（应用商店、九游、TapTap、微信/QQ 小程序等） | 推荐。福利较全，代价是每天看广告需花费时间 |
| 时之沙版（游戏名为「荒野求生」） | 有广告但不能氪金；朱莉、老贝、永久包、月卡、天赋包等可用时之沙购买，300 个时之沙抵氪金版 6 元。缺点是没有活动、无法买氪金奇遇、神秘人抽奖无法抽到某些天赋和图纸 |

**游戏开局**

- 开局可选择已购买解锁的角色与奇遇；同一角色有多个选择时用数字 1、2、3、4 显示，1 号位是基础角色。
- 选定角色后可选择天赋（战斗/生存/探索三行），也可进游戏后再选择。
- 有广告的版本开局可通过观看广告获取一种当局有效的 buff，不满意可多次刷新。
- 有广告版开局广告 buff 共 8 种：外伤上限提高 15、内伤上限提高 15、饥饿上限提高 15、生命值上限提高 30、暴击几率提高 3%、闪避几率提高 3%、基础移动速度提高 5%、基础攻击力提高 10 点。一般选择「基础攻击力提高 10 点」，除非玩闪避流时差那 3% 闪避才能实现全闪（攻略作者观点）。
- 第一次进入游戏开局没有广告，可以死出来重新玩个开局有广告的。想集齐图鉴的，乱石林都不要打，直接开局；若打了乱石林触发金雕剧情，则需在这一局玩下去，等「健康成长」「别离之时」「归来之时」等剧情出来后再重新开局，否则新开局金雕就只有「恍若隔世」，会永久错过部分剧情图鉴。
- 第一局没有二倍速，重开一局一上来就可以选择二倍速。

**营地选址**

| 选项 | 特点 |
|---|---|
| 竹林 | 夜袭多、温度高 |
| 瀑布 | 夜袭少、温度低 |
| 树林 | 比较中庸 |

普通和低挑资源繁衍快时常跑瀑布收集石片、石块与陷阱的鱼，可以选瀑布；也可选树林（位于地图中央，去哪儿都不远，造大船逃离时去野蛮人居住地较近）（攻略作者观点）。

**营地装扮**：在登录界面设置中下拉，若曾在活动中获得过营地装扮，可以换上。

### 4.4 建筑建造和升级选择

营地的建筑有床、工具台、药盒、净水台、火堆、温棚、栅栏、钓鱼码头、宠物室以及专属建筑。床和工具台开局都有，处于一级状态，其他建筑需从头建造。床是唯一不会坏的建筑，其他建筑都会因使用、时间流逝、天气影响或被夜袭踩踏等降低耐久度。

| 建筑 | 建造 / 升级建议 |
|---|---|
| 床 | 一级简陋的床不够用，去海岸弄到阔叶升二级藤木床；三级卧室材料需求大，除非养老否则不升 |
| 工具台 | 一般升级成二级工作台，才能做箭矢、皮甲等；三级工作间和淬毒台只能二选一，普通模式随便做哪个都差不多。在锋利竹枪、毒竹枪、利刃斧、毒刃斧、投掷飞刀、毒液炸药等都没提升的情况下，淬毒台略胜一筹；挑战模式一般每日挑战任务用到哪个升哪个 |
| 药盒 | 要造，是净水台的前置建筑；二级医药台和炼药炉只能二选一（炼药炉见 FAQ 第 12 条），只能做女巫药丸 |
| 净水台 | 只有一级，一般用来做淡水 |
| 火堆 | 一般要升级成二级火炕，才能做肉汤（造大船逃离需要）；三级营火和烘烤炉只能二选一，造大船逃离一般不过冬，不需三级火；二级火炕可烧制木炭；营火可做兽血乱炖、木材/木炭生火，烘烤炉可做咸鱼干和烟熏肉（只能木材生火） |
| 温棚 | 要么不造，要么直接造完升级成温室好种薄荷；生存到第 8 天可以建造 |
| 栅栏 | 一般是不造的，木材紧张拿来造栅栏浪费；造栅栏一般是为了兽潮时多点机会防御住，好去兽穴掏东西（如二十多天那次兽潮，防御住可去丘陵兽穴搞兽皮、草药、兽血、蜂蜜） |
| 钓鱼码头 | 除非有钓鱼挑战任务或想刷钓鱼成就，一般不造；造了可钓加 buff 的鱼（如断网傍晚钓锯齿鲤，+8 基础攻击力） |
| 宠物室 | 要有了白狼才能造；高挑不打湖泊的没机会造 |

> **提示**：二级火炕烧制的木炭，若不用来生火，一般只有朱莉专属的冶金炉会用到。木材生火持续 12 小时，木炭生火持续 24 小时，同时生两种火不会更暖和，只生一种就好。

**各角色专属建筑**

| 角色 | 专属建筑 | 说明 |
|---|---|---|
| 小哥 | 无 | 有野食功能，带木材、生肉、土豆可在野外做烤肉和烤土豆（野外使用要带材料，且不受消耗类提升影响，30 分钟烹饪一次，不会出双份） |

| 老贝 | 高索台 | 可在营地和已解锁的资源循环点之间快速移动且不会迷路，经常出门采集可造 |

## 五、过冬指南

过冬时推图，至少把雨林推掉，屯大量木头和草药；每天出门收集资源带上 4-6 个草药，防止内伤不治；每天在家烧木炭生火取暖。温度 50-55 最冷，最好别出门，睡觉 4 个小时一睡；实在撑不住穿藤甲，吃鳕鱼、兽血乱炖等加温度的东西。

> **提示**：关于生火，过冬一般升营火，烧炭比直接烧木材省不少（攻略作者观点）。

## 六、新手逃离方式选择建议

新人第一次玩，造船逃离最佳。造大船逃离所需通过的关卡少、流程简单，详细条件与材料见同目录 [逃离方式](逃离方式.md)。

> **提示**：本作的获胜方式只有逃离。除造大船外还有火山浪潮、七颗龙珠、混上物资船、修复水中之船、猪皮竹筏等公共方式与各角色专属方式，完整列表与材料要求见 [逃离方式](逃离方式.md)。
