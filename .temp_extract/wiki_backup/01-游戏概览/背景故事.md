# 背景故事

> 本页整理《荒野日记：孤岛》的世界观、主线剧情与各角色的落难来历。
>
> **重要说明**：官方从未发布完整剧情年表。本页内容由「官方公开信息（简介、二周年更新说明）」与「玩家整理的剧情分析（TapTap 长文、玩家文档、玩家群聊记录）」两部分构成，后者属于玩家推测，**不代表官方设定**，仅供参考。

## 一、世界观概述

- **时代背景**：欧洲大航海时代（17–18 世纪），整体设定参照《鲁滨逊漂流记》式的孤岛求生世界观。
- **舞台**：一座看似普通、实为「被人为改造过」的荒岛——岛上有土著的部落、神秘的遗迹、地下的研究设施与鲨鱼出没的沉船海域。
- **官方口径（二周年更新）**：「新增剧情逃出方式：在此逃生方式下玩家将揭开荒岛真正的秘密，看似无意流落荒岛，但实际隐藏着一个巨大的阴谋！」
- **核心悬念（玩家整理）**：名为「五十一区」的组织在荒岛实施「**圣果树计划**」——在岛屿地下修建生物研究设施（即游戏中的「**破风口**」），研究能实现永生、恢复状态的神秘果实（圣果；高科技成品对应游戏道具「仙豆」）。研究失控后，实验蝙蝠逃逸、实验动物变异，岛屿被废弃，留下一个充满危险与秘密的荒岛。

## 二、关键设定要素

| 要素 | 说明 |
|---|---|
| 五十一区 | 玩家整理的幕后组织，实施圣果树计划；沉船中代号「T」的成员即为运送物资人员 |
| 圣果树 | 传说中结出「圣果」的树；罗兰专属地图（圣果树）与其相关 |
| 圣果 | 能恢复状态、追求永生的神秘果实；岛上各方势力争夺的核心 |
| 破风口 | 荒岛地下的研究区域，玩家可探索植物研究室、生物研究室、仓库等设施 |
| 黑暗囚室 | 关押「奈特」的囚室；可直接进入的隐藏区域（需满足开启条件） |
| 奈特（Nate） | 朱莉的哥哥，三年前失踪；研究「神秘果实/神奇豆子」，被囚于荒岛，其手稿记载了「海妖」相关文件 |
| 海妖 | 小哥剧情线中提到的传说生物；玩家推测其守护着古代遗迹与圣果 |
| 古代遗迹 | 小哥专属地图；玩家推测与海妖的守护职责相关 |
| 神秘果实 / 仙豆 | 游戏内道具，与圣果设定相呼应 |

## 三、五位主角的落难来历

> 以下为玩家整理的剧情（来源：TapTap 玩家长文与玩家群聊分析），官方未发布完整版角色剧情文本。

### 3.1 小哥（野食家）

微博美食视频博主，为拍摄海上美食素材出海，途遇海妖歌声与迷雾漩涡，被卷入荒岛。剧情先导中提到「老者讲述海妖守护的神秘岛与七颗彩色圆球」——这也是游戏内[七色圆球逃离方式](../04-攻略指南/逃离方式.md)的由来。

在玩家整理的完整剧情中，小哥是最早登岛者：他在海岸发现了一具尸体（玩家推测为五十一区代号「T」的成员）并将其掩埋；此后进入黑暗囚室（但并未带走奈特）与海妖的古代遗迹，最终通过古代遗迹逃离。

### 3.2 罗兰（美食家）

随船厨师。船长数十年餐厅经验、眼界有限，遂申请随船出海；途中遭遇风暴，流落荒岛。玩家整理剧情中，罗兰在小哥之后登岛：因海岸尸体已被掩埋而找不到线索，转而从土著口中得知「圣果」之事；进入黑暗囚室与奈特对话后看到记载海妖的残破文件；前往圣果树时果实已被海盗摘走，但意外获得海盗留下的地图与沉没的海盗船，最终以「抢夺海盗船」方式逃离。

### 3.3 老贝（探险家）

前英国陆军军官（一说受军方委托随船保护朱莉）。玩家整理剧情中，老贝随军队任务而来，在海岸发现被海盗杀害的同伴尸体（他登岛的第二天）；其后海盗因船沉没在岛上安营（即「海盗营地」专漏洞图的由来）。老贝未去黑暗囚室，而是通过土著的「方舟计划」逃离——对应其专属逃离（热气球）剧情线。

### 3.4 基德（船长）

海盗兼赌徒。与劳伦斯赌博后袭击商船，被坎贝尔家族军舰反抓，海盗船被击沉后落难荒岛。玩家整理剧情中，基德在竹林发现海盗尸体（并拾得扑克牌，对应游戏内「基德打通竹林后获得纸牌」的设定）；数月后救出奈特，却在竹林打猎时杀死了奈特（玩家推测与其对坎贝尔家族/劳伦斯的仇恨有关）；之后回到文明世界向劳伦斯报复，间接导致坎贝尔家族衰落。基德的逃离方式为「建造高塔、获得军舰搭救」。

### 3.5 朱莉（工艺师）

坎贝尔家族的小女儿，哥哥奈特三年前失踪，她与叔叔竞争后继承伯爵爵位。为寻找哥哥随船出海（有「老师线」「军方线」分支），遭遇炮击/风暴后流落荒岛。玩家整理剧情中，朱莉是最后登岛者：在竹林发现已看不清面容的尸体——正是其兄奈特；她通过沉船一侧（桅船）逃离，并在那里发现「整个岛屿是被人设计的」的真相线索。

### 3.6 玩家整理的登岛顺序与真结局推测

- **登岛顺序（玩家推测）**：小哥 → 罗兰 → 老贝 → 基德 → 朱莉。
- **真结局推测（玩家推测，非官方）**：部分玩家认为小哥线的时间线最早、可能构成整个故事的开端；海岸腐尸等要素被用于串联各角色剧情。
- **官方结局文本**：**未检索到**。请勿将玩家推测当作官方设定。

## 四、剧情推进机制

游戏中剧情通过以下途径逐步展开（详见[地图与关卡](../02-核心机制/地图与关卡.md)与[剧情图鉴与收集](../05-收集要素/剧情图鉴与收集.md)）：

| 类型 | 触发方式 | 示例 |
|---|---|---|
| 开场剧情 | 角色开局自动播放 | 五角色各自的开场（帆船倾覆、货船、赌场等） |
| 关键剧情 | 特定行为触发 | 溶洞石屋/峡谷、火山喷发、部落战争、大船出逃、发现龙珠 |
| 建筑剧情 | 满足前置条件回家触发 | 炼药炉（远山女巫）、淬毒台（雨林毒物）、烘烤炉（沉船海盐） |
| NPC 剧情 | 好感度/天数条件 | 母狼上门、骆驼上门、野蛮人上门、金雕、女巫、机关甲人 |
| 专属剧情 | 角色专属地图 | 罗兰-圣果树、朱莉/老贝-海盗营地、小哥-古代遗迹、基德-至高之地 |
| 结局剧情 | 逃离完成 | 各逃离方式对应结局（大船出逃、火山结局、各角色结局） |

### 4.1 关键剧情触发一览（攻略整理）

- **溶洞明暗盘**：规定步数内解开 → 触发峡谷剧情；野蛮人好感 5 星触发智斗或武斗；武斗失败死亡，智斗成功触发造船逃生；智斗超步数完成 → 野蛮人好感清零并触发人物专属逃生剧情，之后清全图开启专属点。
- **部件剧情**：
  - 烘烤炉：沉船打通至少一重后回家触发（营火 2 升 3）；
  - 炼药炉：打通远山选择帮助女巫后回家触发（药台 1 升 2）；
  - 淬毒台：去过雨林并带回毒液后回家触发（工作台 2 升 3）。
- **NPC 开启**：母狼（湖泊通关 + 10 天）、骆驼（绿洲通关 + 20 天）、野蛮人（远山通关 + 20 天）。
