# 角色介绍

> 本页介绍《荒野日记：孤岛》的五位基础角色，以及「基础角色—奇遇」的角色体系结构。

## 一、角色体系概述

游戏中的可选角色分为两类：

- **基础角色**：共 5 位——美食家**罗兰**、工艺师**朱莉**、探险家**老贝**、野食家**小哥**、船长**基德**。基础角色拥有各自的原皮特性（被动能力），使用某一角色或其名下任意奇遇成功逃离（任意逃离方式），可解锁该角色的通关奖励。
- **奇遇**：在基础角色基础上进一步强化的「皮肤」角色，拥有独立的技能树与专属剧情包装（如罗兰的战地厨师、御蜂厨医、新春厨神等）。购买奇遇时必须拥有对应基础角色；若未拥有基础角色，购买时会把基础角色一并打包。**基础角色的所有特性，其名下的奇遇全部拥有。**

> **提示**：不出意外的情况下，一周目零氪玩家可以用初始角色体验完整游戏流程；各角色的差异主要体现在专属建筑、制造加成、战斗技能与专属逃离方式上。

> **术语说明**：玩家社区常用「原皮」指代基础角色本身，用「奇遇」指代付费强化角色；部分奇遇有常用简称（如「异变死神」简称「死基」、「战地厨师」简称「战厨」、「夺宝怪盗」简称「宝基」、「塔罗女巫」简称「塔罗」）。

## 二、罗兰（美食家）

| 项目 | 内容 |
|---|---|
| 定位 | 美食家 / 厨师 |
| 官方简介 | 在厨房摸爬滚打了十二年，有着出色的料理技巧，尤其爱尝试开发新的菜品。但是眼界有限，遂申请成为随船厨师出海。性格豪迈直爽，积极乐观。 |
| 原皮特性 | 烹饪出美味食物的概率更高；可以烹饪**秘制炖肉** |
| 专属建筑 | **酿酒台**（可制作土豆酒） |
| 专属逃离 | 抢夺海盗船逃离（专属地图：圣果树） |
| 通关解锁 | 配方：**荒野烤肉**（解锁后所有角色均可制作） |
| 可制作专属物品 | 秘制炖肉；奇特香料（需先获得配方） |
| 奇遇 | 战地厨师、御蜂厨医、新春厨神、春语妙厨 |

补充说明：

1. 罗兰烹饪出美味食物的概率更高——在制作逃离材料（如肉汤）时出现「美味」品质属于额外结果，不影响正常产出。
2. 罗兰可制作的「奇特香料」不能直接使用，只能用于与野蛮人交易（需先获得配方）。
3. 使用罗兰通关后解锁的「荒野烤肉」配方为账号级解锁，所有角色均可在营火制作。

## 三、朱莉（工艺师）

| 项目 | 内容 |
|---|---|
| 定位 | 工艺师 / 贵族 |
| 官方简介 | 坎贝尔家族的小女儿，哥哥在三年前失踪，与叔叔竞争后继承伯爵爵位。对冶金有着天分，擅长游泳和滑雪，喜爱收集袖珍手枪，还会中国刺绣。 |
| 原皮特性 | 制造出耐久工具的概率更高 |
| 专属建筑 | **冶金炉**（可制作武士刀、重连弩、精致炸药、弹药、伪袖珍手枪等强力武器） |
| 专属逃离 | 制作铁船逃离（专属地图：海盗营地） |
| 通关解锁 | 配方：**朱莉的长弓**（解锁后所有角色均可制作） |
| 可制作专属物品 | 铁锭（开启专属逃离剧情后可炼制）；弹药（需先在神秘遗迹击败蝙蝠王后获得「弹药制造图纸」）；伪袖珍手枪（需先获得配方） |
| 奇遇 | 双旦女爵、幽灵公主、塔罗女巫、冰雪公主 |

补充说明：

1. 朱莉的「制造耐久工具概率更高」指制造时有概率产出更耐久的同名装备，而非其制造的所有装备都更耐用。
2. 铁锭为朱莉专属逃离材料，只能用于专属逃离（用铁矿在冶金炉烧制）。

## 四、老贝（探险家）

| 项目 | 内容 |
|---|---|
| 定位 | 探险家 / 前军官 |
| 官方简介 | 前英国陆军军官，长期的军旅生活使其有着强壮的体格和灵敏的身手。平时不爱说话，做事一板一眼。但是很爱喝酒。 |
| 原皮特性 | 迷路概率降低 |
| 专属建筑 | **高索台**（可大大缩短营地到各资源点之间来回的时间） |
| 专属逃离 | 热气球逃离（专属地图：海盗营地） |
| 通关解锁 | 配方：**老贝的草裙**（解锁后所有角色均可制作） |
| 可制作专属物品 | 老贝的研磨器（将石块打磨成石片，需先获得配方） |
| 奇遇 | 不屈军魂、狂化战士、赏金猎人 |

## 五、小哥（野食家）

| 项目 | 内容 |
|---|---|
| 定位 | 野食家 / 美食视频博主 |
| 官方简介 | 微博美食视频博主，一本正经做美食节目，不被时间和社会束缚，随心所欲地填饱肚子。有着「食在野，醉在食」的能力。 |
| 原皮特性 | 可在非营地的地方制作食物（野食）；食用食物或药品后 1 小时内基础攻击力 +7，并恢复失眠值 |
| 专属建筑 | 无 |
| 专属逃离 | 穿越逃离（专属地图：古代遗迹） |
| 通关解锁 | **小哥的手电**（所有角色开局携带，相当于更轻便持久且轻量的火把） |
| 可制作专属物品 | 小哥肉酱（需先获得配方） |
| 奇遇 | 元日食神、圣诞小哥、绝味小哥 |

补充说明：

1. 小哥的野外制作需要随身携带木材与生肉/土豆，且不享受科技加成。
2. 食用食物或药品后 1 小时内「基础攻击力 +7」对近战、远程、投掷均有效；吃膏药、绷带等药品同样触发；同时附带约 12% 的近武/远武命中率加成（详见[战斗系统](../02-核心机制/战斗系统.md)与[资料来源](../附录/资料来源.md)）。

## 六、基德（船长）

| 项目 | 内容 |
|---|---|
| 定位 | 船长 / 海盗与赌徒 |
| 官方简介 | 大名鼎鼎的基德船长，身为海盗的同时也是一名赌徒。认为自己是航海家，偶尔在海上和别人做做生意。精通社会交际。 |
| 原皮特性 | 战斗中有概率怒吼（恐吓）使怪物直接失去战斗力；可通过燃烧纸牌窥探命运（获得增益） |
| 专属建筑 | **赌桌**（烧牌获得 buff；打通竹林后触发剧情获得纸牌后可制作） |
| 专属逃离 | 建造高塔，获得军舰搭救（专属地图：至高之地） |
| 通关解锁 | **基德的罗盘**（所有角色开局携带，可显示当前地图循环资源点的资源是否已满） |
| 可制作专属物品 | 纸牌（需先获得配方） |
| 奇遇 | 夺宝怪盗、异变死神、新月狼人、彩蛋兔爷 |

补充说明：

1. 基德的怒吼（恐吓）直接使怪物丧失战斗力。被恐吓的怪物计入每日挑战的「击败」进度，但不计入成就中「杀死多少只某类怪物」的统计。
2. 基德烧牌（赌桌）的具体牌面效果见[物品图鉴](../03-数据资料/物品图鉴.md)与[战斗系统](../02-核心机制/战斗系统.md)。

## 七、角色与玩法流派

角色的原皮特性直接影响流派选择，玩家社区常见的流派与适配关系（攻略作者观点，仅供参考）：

| 流派 | 核心思路 | 常见适配角色/奇遇 |
|---|---|---|
| 强攻流 | 提高单次攻击伤害，快速击杀 | 罗兰（战地厨师）、小哥（元日食神）、基德（异变死神） |
| 闪避流 | 提高闪避，无伤周旋 | 基德（夺宝怪盗）、小哥（绝味小哥）、老贝（不屈军魂/赏金猎人） |
| 击退流 | 依靠击退拉开距离 | 朱莉（双旦女爵、冰雪公主） |
| 毒伤流 | 依靠中毒持续伤害 | 基德（毒刃斧体系）、相关中毒武器体系 |
| 养老流 | 长天数生存与循环资源经营 | 罗兰（御蜂厨医）、小哥（绝味小哥） |

> **提示**：流派的达成高度依赖[天赋](../02-核心机制/天赋系统.md)与[奇遇](../02-核心机制/奇遇系统.md)的组合，新人建议先熟悉基础角色再考虑奇遇搭配。
