# 挑战模式

> 挑战模式在普通模式基础上逐级提高难度，增加专属怪物与「挑战主题」机制，是高难度资源与局外奖励的主要来源。

## 一、模式解锁与难度进阶

- 普通模式生存满 10 天，从第 11 天起可不用通关直接进入挑战模式（攻略作者提示：此法仅适合老玩家开新号）。
- 普通模式与挑战模式的存档**不能并存**：一个模式未逃离且有进度可读的情况下进入另一模式，当前存档会被删除。
- 初始可选择的挑战难度只有**挑战 1 与挑战 2**。
- 进阶规则：**偶数难度打通后可跨越上方奇数难度，直接挑战下一个偶数难度；奇数难度打通后不能跨越下一个偶数难度。**
- 推荐进阶顺序：**2 → 4 → 6 → 8 → 10 → 12 → 14 → 15**。

> **提示**：挑战模式天数为「越两级」解锁制（如挑战 4 通关后可打挑战 6），社区通常按 低挑（1–4）、中挑（6–9）、高挑（10–15）划分阶段。

## 二、挑战模式的核心差异

随挑战难度提高，游戏发生以下变化：

1. **怪物属性提升**：怪物攻击力与生命值大幅提高，随生存天数进一步成长（详见[生物图鉴](../03-数据资料/生物图鉴.md)）。
2. **状态衰减加快**：饥饿度、精神、失眠值的衰减速度随难度增大。
3. **循环资源点变慢**：资源繁衍与采光后的再生速度均变慢；挑 10 以后许多资源基本需要「采光等再生」。
4. **新增挑战专属野怪**：狐狸、鬣狗、河马、猩猩、毒蝎、鳄龟、豹等（见下文）。
5. **出现挑战主题**：每局随机叠加若干负面/机制性主题（见下文）。

各挑战专属野怪的出现地图（据攻略资料整理）：

| 怪物 | 出现地图 |
|---|---|
| 狐狸 | 远山、松木林 |
| 鬣狗 | 乱石林 |
| 河马 | 沼泽湿地、湖泊 |
| 猩猩 | 雨林、原始森林 |
| 毒蝎 | 溶洞、野人洞窟、戈壁遗迹 |
| 鳄龟 | 林中暗流、瀑布 |
| 豹 | 火山、荒漠、绿洲 |

此外，多个关卡会新增怪物波次（如灌木丛在挑战模式新增一波毒蛇）。

## 三、挑战主题

### 3.1 机制说明

- 挑战主题**每晚现实时间 0 点重新随机**（0 点在游戏内时，睡觉并写下日记后变更）；偶尔会连续两天主题相同，但极为罕见。
- 所有玩家的挑战主题相同。
- 主题数量随难度增加，同一类别内随机抽取：

| 挑战难度 | 主题池构成 |
|---|---|
| 挑 1–3 | 「漫天金星 / 剧毒之心」二选一 |
| 挑 4–6 | 以上二选一 + 「纵姿豪迈 / 天气预报 / 寒霜时代」三选一 |
| 挑 7–9 | 以上 + 「背水一击 / 人体描边 / 兽血沸腾 / 集结号角」四选一 |
| 挑 10–12 | 以上 + 「月圆之夜 / 薄雾冥冥」二选一 |
| 挑 13–15 | 以上 + 「极昼 / 极夜」二选一（共五种主题同时生效） |

### 3.2 主题效果一览

| 主题 | 效果 | 应对参考（玩家总结） |
|---|---|---|
| 剧毒之心 | 生物攻击有 10% 概率造成中毒（原本有毒的生物概率做加法）；中毒共跳 3 次伤害，每次损失「本次判定时剩余生命值」的十分之一，以生物攻速判定，中毒期间再次中毒会刷新效果 | 避毒丸、某人的新衣（抗毒）、皮甲抗毒科技 |
| 漫天金星 | 生物攻击有 10% 概率造成眩晕（同上）；眩晕会阻止下次攻击（不叠加，重复触发仅刷新）。熊、河马等重量级怪物概率更高；被晕眩后怪物晕眩概率还会临时提高（仅一次） | 强身丸、某人的新衣（抗晕） |
| 寒霜时代 | 温度额外降低 10℃ | 保暖食物/衣物；极昼时影响较小 |
| 纵姿豪迈 | 装备的耐久消耗加倍 | 养护者天赋、多备武器 |
| 天气预报 | 恶劣天气（雾、雷雨等）出现概率上升；主要影响温度、七色圆球收集、鱼类钓取（与命中无关，与竹筒哑火无关——后者存疑）；频繁恶劣天气加速建筑耐久损耗 | 及时升级/更换建筑；建筑师天赋 |
| 集结号角 | 敌人数量有约 10% 概率翻倍 | 闪避流影响较小；注意耐久与消耗 |
| 兽血沸腾 | 生物血量低于 25% 后攻击力加成约 25% | 秒杀、怒吼、击退、闪避等速杀手段 |
| 背水一击 | 生物死亡时约 26.7% 概率再打出一击：不可闪避，可附带中毒/眩晕；基德怒吼（恐吓）可阻止触发 | 提高生命值（大家伙、强健），不要残血贪战 |
| 人体描边 | 提高生物 15% 闪避率，相当于降低我方命中 | 神射手、章鱼料理、强屯/殊死等命中加成 |
| 月圆之夜 | 夜袭概率与强度提高 | 夜语者天赋、防狼广告、白狼守家 |
| 薄雾冥冥 | 迷路概率上升（与路程、经过点有关） | 火把/小哥手电、占星师天赋；迷路走法见[小游戏攻略](../04-攻略指南/小游戏攻略.md) |
| 极昼 | 全天判定为白天，没有黑夜；路袭概率降低、失眠加剧，影响海岸龙珠获取与吸血女爵奇遇发挥 | 省火把、温度较高；但睡觉恢复生命较困难 |
| 极夜 | 全天判定为黑夜（实际白天仍会亮，只是黑夜更长）；失眠缓和、路袭概率增加，未携带照明工具将降低 30% 远武命中率 | 火把消耗大，注意照明与温度 |

> **提示**：攻略作者建议过挑时避开「人体描边」与「背水一击」两个主题，它们会显著提高战斗风险。

> **挑 15 主题组合规律（玩家整理）**：挑 15 的五个主题槽实际只有 4×3=12 种组合，常见规律为——「满天金星系」（极昼 + 人体描边/背水一击/薄雾冥冥/月圆之夜）配「纵姿豪迈/寒霜时代/天气预报」三选一；「剧毒之心系」（极夜 + 集结号角/兽血沸腾/月圆之夜/薄雾冥冥）配「纵姿豪迈/寒霜时代/天气预报」三选一。玩家普遍认为「兽血沸腾」是对奇遇与玩家最友好的主题。

## 四、挑战任务与奖励

- 挑战模式下，在对应难度完成**每日挑战任务**（制作、击杀、生存、钓鱼等类型）与**每周挑战任务**（均为逃离任务）可领取奖励。
- 奖励领取规则：在当前挑战等级完成任务后，**可同时领取本级及所有下级等级的奖励**。
- 由于「越两级」机制，常见玩法为：在 X 难度完成逃离领周挑奖励，再到 X+2 难度做日挑任务。
- 挑战任务产出**天赋原石**；挑战 10 及以上任务额外产出**天赋结晶**。书页的主要来源之一为「贝壳狂欢」与周日挑任务。

详见[账号资源系统](../05-收集要素/账号资源系统.md)与[挑战攻略](../04-攻略指南/挑战攻略.md)。

## 五、挑战模式推荐逃离方式（概述）

- 挑战模式最推荐**建造大船逃离**：需要通过的关卡相对少、流程简单，最快约 35 天可以逃离（20 天刷满野蛮人好感并获胜 + 15 天领取 30 个结实木材）。
- 挑战模式建议携带奇遇（付费强化角色）进行游玩，低挑推荐强攻流（战地厨师、异变死神、元日食神等），新人高挑可先从击退流与闪避流入手。

详见[逃离方式](../04-攻略指南/逃离方式.md)。
